# Проверка task-workflows

Версия: 1.4.0.20261108workflow8, ветка codex/task-workflows.

- Собран standalone-состав: 613 production Java-файлов без исходного CodePilot JAR.
- Полный набор: 565 успешных Java-тестов, проверка границ standalone-продукта. Update-site собирается штатным Eclipse Publisher.
- Основное и повторное независимое ревью: исправлены семь подтверждённых дефектов; финальная независимая проверка не обнаружила блокеров. [Подробности](review-20261108-workflow8.md).
- В отдельной EDT 2026.1.2.2 создан настоящий проект и новая файловая база 1С 8.3.27.2325 через native EDT API; выполнено FULL-обновление.
- Через настоящий HTTP MCP EDT проверены receipt и обнаружение изменения файла, сохранённая привязка сессии, действие и проверка результата, отсутствие дубля, ожидание собственного задания, scoped form-change delta, ожидание условия формы и отрицательный таймаут.
- Дополнительно проверены отказы при некорректном ответе сообщений и разрыве отрицательного текстового условия на границе фрагментов. Они не дают ложного успеха.
- Для UI использован управляемый сервер с протоколом Vanessa, не настоящий TestClient. Приёмка пользовательских форм реальной Vanessa этим прогоном не заявляется.
- Реальная уборка при завершающей записи EDT в журнал безопасно сохранила базу. После уточнения правила для generated event log и перезапуска EDT уборка успешно продолжена через MCP: удалены база, quarantine, запись запуска, собственные настройки приложения и audit-проект; сессия закрыта. При ещё не готовом контексте проекта операция отказала без удаления; повтор после готовности завершился.
- Четыре завершённые живые фикстуры (три первоначальные и одна после ревью) полностью убраны, включая собственные UUID в Eclipse preferences. Никаких правил доверия/UAC в этих проверках не добавлялось.
- Журнал данных был пустым: новая живая проверка mark_deletion непустого журнала не заявляется. Восстановление prepared-intent, события, source checkpoints и блокировка устаревшего плана подтверждены регрессиями.

Локальные evidence: .runs/task8 и .runs/task8-review (build.log, tests.log, live.json, cleanup.json). Рабочая EDT пользователя/x5 не менялись. Установка кандидата — только в отдельную EDT Agent Bridge Dev. Полный новый прогон настоящего сценария Vanessa и серверный кластер этим выпуском не проверялись.
