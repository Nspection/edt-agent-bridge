# Ревью Native host 8.5 — 09.11.2026

Основное ревью и независимое read-only ревью выполнены относительно main a19a426. Проверены возвращаемые значения Native API, жизненный цикл канала, ownership/hash-защита удаления исходников, осиротевшие регистрации, порядок блокировок host, reentrant lease FULL и строго типизированные доказательства отсутствия объекта.

Исправлено повреждение кириллицы в описании MCP-команды: агент снова получает правильные идентификаторы ПараметрыВызова и Результат. В recovery-инструкцию добавлено ограничение фиксированного ключа запроса: повтор с тем же borrowed verifier читает исходный результат; после известного отрицательного исхода нужен обычный cleanup либо другой проверенный host.

Независимое ревью не выявило оставшихся блокирующих замечаний. Ревьюер не менял файлы и не запускал пользовательскую EDT или базы. Runtime-доказательства проверены отдельно; повторный runtime в рамках релизного ревью не выполнялся.

NOT_EQUAL после перезапуска EDT остаётся открытым наблюдением, а не исправленной ошибкой или подтверждением готовности базы.
