# EDT Agent Bridge 1.4.0.20261109zmodes2

В верхнюю панель табличного объединения добавлено меню «Объединение макета»:

- взять текущую конфигурацию целиком;
- взять конфигурацию-источник целиком;
- объединить с приоритетом текущей;
- объединить с приоритетом источника.

При общем предке сохраняются независимые изменения, а приоритет выбирает сторону в конфликтах свойств. Структурные сдвиги остаются для ручного решения. Без предка объединение всех уникальных строк не гарантируется.

Пересчёт заменяет ручные правки только после подтверждения; исходники не меняются до штатного применения плана EDT. Через MCP доступен тот же механизм: `edt_merge_result(action=merge_mode)` с mode, `replace_result=true` и свежим expected_node_sha256. Несохранённые черновики блокируют вызов. Команды отдельных отличий сохранены.

Проведены основное и независимое ревью. Исправлено заполнение выпадающего меню перед показом. 585 Java-тестов, 29 PowerShell-контрактов, native UI и MCP в отдельной EDT прошли. Проверены подтверждение/отмена, грязный черновик, устаревший hash и сохранность исходников. Три тестовых проекта и временные артефакты удалены; БД не создавались.
