# Инцидент тестовой среды 12.11.2026 и решение по выпуску

Штатный `avp.com REPORT AMSI` подтвердил детект `PDM:Trojan.Win32.Generic`: завершение pwsh и удаление test-managed-vanessa.ps1 в22:34:10 и диагностического trace.ps1 в22:43:15. В отчёте указан поведенческий анализ. Ложное срабатывание не установлено. Отдельное поле ProcessSha256 Windows avp4662 не интерпретируется как доказанный SHA исходного файла: область его хеширования неизвестна. Сопоставление сохранённого текста не доказывает byte-identity удалённого объекта.

Старые обнаруженные файлы не восстанавливались и повторно не исполнялись. Исключения, настройки AV и защиты Windows не менялись; данные и исходники третьим лицам на анализ не отправлялись. Исторический инцидент сохраняется с неизвестной классификацией.

Удалённый тестовый harness заменён архитектурно: production CLI и новый тест используют общий managed-vanessa-core.ps1. Все33 прежних контракта сопоставлены с решениями и запрещёнными эффектами. Сценарии работают в памяти; нет глобальной подмены системных команд, имитации EXE, изменения LOCALAPPDATA, записи настроек доверия, сокетов или команд остановки реальных процессов. Отдельный smoke вызывает настоящий CLI только для idle Status, отклонённого Continue и absent Stop на новом маркированном пустом каталоге. Семь штатных действий production CLI сохранены. [Карта покрытия](managed-controller-contracts.md).

До первого запуска независимый рецензент проверил фактические хеши контроллера/core/harness и соответствие PDE-копиям. Контроллер и core поставляются вместе; Java проверяет байты перед запуском и teardown. Обязательная managed_powershell стадия сохранена, old test не пропущен: её функциональное покрытие перенесено на shared production core.

На кандидате1.4.0.20261113audit1 прошёл полный обязательный набор, включая33 контракта и3 CLI smoke. После нового контроллера и общего прогона новых avp4662 не наблюдалось; штатные STATUS AMSI и STATUS File_Monitoring вернули running. Это наблюдение текущей среды, а не доказательство безвредности исторического объекта.

Независимое ревью конкретного пакета не выявило подтверждённого security-блокера текущего продукта. Решение на выпуск относится только к совпадающим version/archive SHA256/verification run и просмотренным production-ресурсам; оно не переопределяет детект старого теста. Несовпадение исходников/пакета, непройденная обязательная проверка или новое относящееся к артефакту обнаружение отменяют допуск. Финальная живая приёмка и уборка проверяются отдельно. Полные отчёты AV остаются локально, в публикацию не входят.
