# EDT Agent Bridge 1.4.0.20261118table1

В прямом TestClient на 1С 8.5.1 команда `table_open` проверяет строку под курсором через `GET_CURRENT_ROW`. Открытие больше не зависит от количества выделенных строк. Если текущую строку не удалось подтвердить после полного ответа RPC, Bridge завершает операцию до активации с `current_row_unproven` и сохраняет рабочий канал.

Точное совпадение строки, проверки исходной и целевой формы и защита от повторного действия при неизвестном исходе сохранены. Открытие карточек проверено в изолированной EDT на одноразовой базе 1С 8.5.1.1522 со 120 записями. [Протокол проверки](review-20261118-dynamic-list.md).
