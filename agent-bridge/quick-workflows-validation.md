# Проверка короткого рабочего цикла — 2026-11-08

Кандидат: `1.4.0.20261108workflow4`. Релиз не опубликован: полный живой прогон Vanessa не завершён.

- 461 Java-регрессия на финальных JAR и 24 контракта PowerShell прошли. Включены повтор запроса после перезапуска, утрата снимка, cursor paging, ограничения текста и отказ конфликтующим аргументам.
- Локальный штатный p2 verify-only прошёл в отдельном профиле; установочный ZIP собран.
- В отдельной EDT загружен финальный кандидат. Через MCP проверены новые схемы, сводка реального проекта/базы с именем и UUID, профиль и защиты запуска.
- Созданы два native-проекта и две собственные файловые базы 8.3.27.2325: целевая и менеджер Vanessa. Каталог создан фабрикой EDT после первой загрузки для проверки последующего обновления.
- Живой сценарий не запускался: штатная подготовка доверия менеджера потребовала записи в Program Files, Windows отменил запрос повышения прав. Это внешний блокер, не успешная runtime-проверка.
- Оба проекта удалены через EDT, профиль удалён, записи списка запуска проверены, обе базы и корень фикстуры удалены. Временное правило доверия отсутствует. Своя EDT и её JVM закрыты; пользовательская EDT не затрагивалась.

Регрессионные тесты с управляемым backend не заменяют живой сценарий Vanessa. До него не заявлены проверка реального UI/checkpoint и полный цикл новой короткой команды. Публикация релиза отложена; публичная версия остаётся spreadsheet2.
