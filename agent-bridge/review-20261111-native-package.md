# Ревью автоподготовки Native

Diff относительно 241118f проверен собственным и независимым ревью. Проверены закреплённые ZIP/DLL SHA256, состав/manifest/размеры архива, ограничение HTTPS origins, отсутствие секретов, ограниченный кеш, сохранение изменённых файлов, singleflight, отмена/lifecycle, работа UI вне сети/диска и единый backend MCP/startup/default prepare.

Подтверждённых P1/P2 независимое ревью не выявило; его UX-замечание исправлено: после успешного Apply сбрасывается dirty, чтобы принимать последующие изменения настройки через MCP; отдельный isolated harness на актуальном сервисе: 10/10 PASS. Общий прогон: 914 Java, standalone boundary, 41 worker +16 table. Живая проверка в своей EDT: холодная автозагрузка, кеш без повторной загрузки, MCP-повтор, отклонение повреждения, восстановление с сохранением повреждённых байтов, общая настройка и повторный запуск EDT. Эта приёмка проверяет поставку пакета; запуск/исполнение Native host и изменение базы в этом этапе не повторяются.

Пользовательские EDT/базы не используются. Свой новый кеш удаляется и исходные настройки/конфигурация private EDT восстанавливаются. Релизная сборка проверяется resolver p2, после merge сравниваются классы и содержимое JAR; публичный обычный URL проверяется по версии, SHA256 и resolver.
