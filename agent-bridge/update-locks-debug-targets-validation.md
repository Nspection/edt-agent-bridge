## Живая проверка в своей EDT

Отдельные установка/workspace `EDT Agent Bridge Dev` / `EDT-Agent-Bridge-Dev`, MCP 8769. Одноразовый проект `BridgeCreationUiReusece5f03f9`, файловая база UUID `928dbbb6-39a2-470a-a995-45c0bece02b6`, платформа Windows x64 8.5.1.1522. Порт пользовательского отладчика 1552 не использовался.

1. Собственный тонкий TestClient удерживал базу. Native incremental update остановился на штатном вопросе исключительной блокировки; MCP вернул исходный job, UUID базы и свежий хеш вопроса. Ответ с устаревшим хешем отклонён, клиент остался подключён. После свежего preview уборки `close_owned_and_retry` закрыл свой клиент и продолжил тот же update. Исходный job завершился, native equality стал EQUAL. Этот SDK-прогон выполнен на dev4; после него были добавлены сценарии запуска и исправления чтения SDK-настроек.
2. На dev9 изменён собственный объект: `launch` с политикой ask вернул `awaiting_decision` до SDK-запуска, без job и окна. Вариант cancel не запустил обновление. Другой запрос получил подтверждение update_and_launch, обновил базу до EQUAL и запустил native-отладку на отдельном локальном порту 56136.
3. На том же реальном native target выполнены preview/apply, чтение выставленного набора типов, restore_preview/restore, проверка исходного набора. Собственная отладочная сессия закрыта. Проверена именно настройка автоподключения; исполнение каждого типа предмета не проверялось.
4. На финальном dev11 отдельный временный проверочный bundle создал стандартный JFace MessageDialog с вопросом обновления внутри зарегистрированного потока своей базы. Явный ответ MCP и автоматический ответ при task-scoped разрешении выбрали «Обновить и запустить». Watchdog не сработал. Это синтетическая проверка обработки окна: она не выполняла обновление базы. Реальная загрузка и SDK-запуск проверены отдельно пунктом 2.

Промежуточный запуск показал штатный вопрос «Обновление приложения»; пользователь отменил его. После этого введён preflight-выбор до SDK-вызова. Computer Use не управлял javaw. Проверочный bundle предназначен только для теста и не входит в продукт.

## Границы

Не проверены кластерная база, HTTP/web/mobile-предметы в исполнении, другие версии SDK и локализации. Распознаются только известные штатные вопросы, синхронно вызванные зарегистрированным потоком. Запросы безопасности/доверия и произвольные окна не обрабатываются. Пустая область native target не обещает изоляцию одной базы. Успешная настройка типов и запуск не являются приёмкой прикладного сценария.
