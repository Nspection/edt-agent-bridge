# Ревью workflow6: проверка изменений и тестовые данные

Проверен весь неопубликованный diff от 87e8d5c: edt_check, журнал данных, фиксированные BSL-рецепты, связанные наборы, схемы/регистрация, сборка и справка. После первичных исправлений проведено отдельное независимое ревью другим агентом без редактирования исходников.

## Исправлено

- Потеря точности чисел на HTTP-входе и в результате native host: BigDecimal вместо промежуточного Double, точные JSON-RPC ID. Есть регрессии через настоящий HTTP endpoint и native-канал с восстановлением ответа.
- Неполные сравнения файлов: пропущенный хеш или файл вне baseline явно остаются неизвестными в кратком ответе. Чтение ограничено 8 MiB/файл и 64 MiB/снимок; идентичные снимки переиспользуются.
- Потерянный ответ агрегату: подтверждённые записи восстанавливаются из журнала до подготовки уборки. Уборка отдельной командой подхватывается набором без новой записи.
- Недостоверный кэш уборки: происхождение и терминальный результат сверяются с журналом; `dependent_retained` требует реально оставшегося дочернего объекта.
- Ложное подтверждение отката при вмешательстве обработчика: после отката проверяется фактическое состояние ссылки/версии/пометки. Сохранившееся изменение требует разбора исхода.
- Повтор завершённой уборки не требует работающего host. Новая запись при неизвестном исходе не отправляется.
