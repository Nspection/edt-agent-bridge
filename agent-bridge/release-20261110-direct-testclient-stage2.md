# EDT Agent Bridge 1.4.0.20261110testclient2

Второй этап прямого TestClient: чтение выбранных строк/колонок, уникальный выбор строки, защищённое добавление и заполнение ячеек, в том числе в пакетах до16 шагов. Прежний маршрут Vanessa сохранён.

Основное и независимое ревью выявили три P1 и один P2; исправления повторно проверены. Пустая/неподтверждённая выборка больше не даёт ложный успех; ввод разрешён только в доказанную новую/целевую строку, включая проверки после обработчиков EndEdit. Окно и поля проверяются по одному финальному снимку. Неизвестные операции не повторяются.

683 Java-теста, 7 worker-контрактов и16 table-контрактов. Runtime — собственная EDT и одноразовая база8.5.1.1522. Публичный p2 проверяется отдельно от пользовательского профиля.

Ограничения: Windows, отдельный Python; плоские таблицы с множественным выделением и доказуемой непустой исходной выборкой. Добавление требует возможности завершить пустую новую строку перед вводом; формы с иной валидацией или неоднозначными descriptors отклоняются. Пустая таблица не считается подтверждённой; очистка ячеек, сложные/ссылочные редакторы не включены. Чтение меняет выделение собственного клиента. Пакет не является транзакцией.
