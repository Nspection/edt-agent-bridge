# EDT Agent Bridge 1.4.0.20261118zzgithub1

В настройках **EDT Agent Bridge → Багрепорты в GitHub** кнопка **Подключить GitHub** сразу запускает вход в браузере. После проверки в EDT виден подключённый аккаунт.

Кнопка **Войти с токеном…** открывает отдельное окно с защищённым полем. **Создать токен** открывает страницу GitHub с подготовленным названием и правом public_repo.

Если Git Credential Manager отсутствует, Bridge предлагает открыть форму нового Issue в браузере. Пользователь заполняет и отправляет её на GitHub.
