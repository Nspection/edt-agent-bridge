# EDT Agent Bridge 1.4.0.20261108workflow6

ИИ-агенту проще проверять изменения и готовить тестовые данные, сохраняя возможность делать каждый шаг отдельно.

- `edt_check`: baseline, обзор Git-изменений/объектов и новых диагностик, порционные подробности, объединение с результатом выбранного сценария Vanessa.
- `edt_test_data`: журнал, подтверждённое создание справочников/документов и именованные связанные наборы; ручные шаги по умолчанию, автоматический режим по запросу, pause/advance/resume.
- Безопасная уборка: только пометка удаления неизменённых собственных объектов, обратный порядок, сохранение родителей при оставшемся дочернем объекте. Отдельные primitive-команды совместимы с наборами.
- Точная передача чисел по HTTP и native host; восстановление после потерянных ответов; проверки фактического состояния после отката.
- Ограниченное чтение больших файлов и явная неопределённость вместо ложного нуля изменений.

520 Java-регрессий, независимое ревью и проверка standalone/p2. Реальные проверки — в отдельной EDT 2026.1.2.2 / Java17 / файловой 1С 8.3.27.2325: Git/диагностики, Vanessa, создание и связи, шаги/пауза/продолжение, защищённая уборка. Кластер, 8.5 и прикладные обработчики x5 этим прогоном не охвачены. Статические маркеры и успешный выбранный сценарий не являются доказательством полного покрытия приложения.

Установка/обновление по прежнему адресу: https://nspection.github.io/edt-agent-bridge/ — «Справка → Проверить обновления», затем перезапуск EDT и обновление инструментов MCP в клиенте.

Native ZIP и AgentHost.epf включены в релиз; SHA-256 — в SHA256SUMS.txt. Собственные тестовые базы, проекты и правила доверия после проверки удаляются; пользовательская EDT не меняется.
