# EDT Agent Bridge 1.4.0.20261111zzzzzzzzzstable1

Прямой TestClient использует согласованный60с бюджет операции/ответа вместо25с/10с. Полный отрицательный ответ и доказанный таймаут до отправки сохраняют исправный канал; неполный ответ по-прежнему закрывает его. Unknown блокирует новые мутации даже с новым ключом, оставляя чтение/диагностику. Исходный ключ читает сохранённый результат после остановки клиента.

Добавлены безопасная диагностика PID/RPC/этапов/таймингов, historical last_failure и её сохранение в compact UI. Собственное и независимое ревью, исправления no-replay;959 Java +74 Python-проверок. В своей базе8.5 тонкий клиент открыл реальную32-секундную форму и закрыл её на том же канале; принудительный обрыв собственного клиента вернул unknown с диагностикой. Точный TMS-инцидент и живой модальный диалог не проверены. Native не изменялся; пользовательская EDT/базы не тронуты.
