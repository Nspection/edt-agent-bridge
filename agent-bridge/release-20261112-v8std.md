# EDT Agent Bridge 1.4.0.20261112zzzv8std1

Диагностики получили справочные ссылки v8std: явные BSLLS/АПК ID и подтверждённые уникальным contributor ID v8-code-style. edt_check/get_diagnostics/get_problem_summary сохраняют прежние сообщения и результаты, добавляя отдельный дедуплицированный блок. Кеш, фоновое разрешение, next_call, явные unknown/stale/offline и opt-out не требуют новых MCP-инструментов.

Внешнему сервису передаются только проверенные коды, без исходников, сообщений, путей и настроек EDT. Краткое описание статьи помечено как article_intro, не считается точным правилом для конкретного предупреждения. При отказе справки исходная диагностика остаётся доступной.

1002 Java-теста, standalone boundary, собственное и независимое ревью; отдельная OSGi/EDT-проверка и настоящий публичный v8std. Базы 1С и пользовательская EDT не затрагивались; Native/BSL/worker не менялись. [Контракт и ограничения](diagnostic-standards.md), [ревью и приёмка](review-20261112-v8std.md).
