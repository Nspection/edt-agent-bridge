# EDT Agent Bridge 1.4.0.20261112native3

Native-пакеты получили wait/assert/read, управляемые сроки ожидания и сохраняемый progress. Ошибка условия останавливает зависимые шаги и может сохранить снимок. Выборка JSON-путей уменьшает ответы; крупные значения и ошибки ограничены явно. Последний подтверждённый progress остаётся доступен после остановки клиента. Повторяется только frozen acknowledgement, а не исполнившийся BSL.

Native DLL/ZIP и его транспорт не менялись. Обновлены плагин и шаблон обработки, standalone AgentHost.epf пересобрана штатным механизмом EDT. Прежние code-only шаги сохранены; новые возможности требуют нового host с batch_controls_v1. Сетка/линейки и оригинальные снимки сохранены.

968 Java +74 Python-проверки, собственное и независимое ревью. Приёмка только в собственной базе 8.5: готовность после 32 секунд, проверки/проекции, deadline/overrun, снимок при ошибке, крупная ошибка и progress после stop. Это не проверка конкретной карты TMS. Синхронный BSL нельзя прервать wait-timeout; read/wait требуют кода без побочных эффектов от вызывающего. Пользовательская EDT и базы не затрагивались.
