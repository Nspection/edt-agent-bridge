# EDT Agent Bridge 1.4.0.20261109zzztestclient1

Прямое управление собственным клиентом тестирования 1С через `edt_test_client` и `transport=testclient`, без менеджера Vanessa и без временной обработки. Прежний маршрут Vanessa остаётся доступен по умолчанию.

- Наблюдение формы, ввод, команды, открытие и закрытие; пакет до 16 действий с проверками результата и остановкой при ошибке или неизвестном исходе.
- Проверка базы, PID, времени запуска и владельца порта; журнал ключей идемпотентности без автоматического повтора операций.
- Исправлены закрытие канала при сбое отправки, гонка ограничения числа клиентов и повторное использование регистрации базы менеджера Vanessa.
- Проверены 680 Java-тестов, 7 Python-контрактов и p2 verifyOnly на отдельной копии профиля. Основное и независимое ревью завершены, замечания исправлены и перепроверены.

На своей базе 8.5.1.1522 полный цикл создания/записи/повторного открытия: Vanessa 4,98 с /14 MCP-вызовов; прямой маршрут 2,97 с /14; пакет 1,00 с /3. Медианы трёх прогонов, без запуска и подготовки среды; JSON пакета меньше примерно на55%. Это не измерение стоимости токенов.

Первый этап: Windows, тонкий клиент, обычные элементы управляемых форм; требуется отдельный Python с pywin32/cryptography. Работа со строками таблиц не добавлена. Пакет не является транзакцией. Нагрузочные и иные версии платформы не проверены. Все собственные базы/проекты/клиенты проверки убраны, временные настройки восстановлены. Пользовательская EDT и базы не использовались.
