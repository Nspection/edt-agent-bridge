# EDT Agent Bridge 1.4.0.20261107spreadsheet1

В штатном сравнении EDT рядом с обычной шестерёнкой появилась команда табличного объединения MXLX. Доступны наши данные, источник, общий предок при трёхстороннем сравнении и редактируемый результат. Вкладки: «Текущая конфигурация» → «Результат объединения» → «Конфигурация-источник» → «Общий предок» (если есть). Сохранение меняет план сравнения; исходники изменяются после штатного объединения.

Ручные сеансы доступны агенту через MCP. `edt_merge_result` поддерживает чтение табличных сторон, `open_ui`, `close_ui` и `patch_cells`. Сохранённые ручные изменения и правки агента используют общий native-план. Несохранённый черновик блокирует объединение; изменение исходных файлов требует повторной подготовки результата.

Исправлены обращения к UI-модели из фонового потока, повторная проверка значка после временной ошибки и восстановление временных MCP-окон с недействительными идентификаторами. У неподдерживаемых строк ячейка остаётся пустой. Перспективы не сбрасываются.

Проверки: 421 Java-тест; живые двух- и трёхсторонние сравнения, ручная правка ячейки, сохранение в план и применение из UI и MCP, блокировка грязного черновика и изменённых исходников, повторное открытие значка и пустые неподдерживаемые строки. Три собственных тестовых проекта удалены; базы для этих проверок не создавались.

Ограничения: Windows x64, EDT 2026.1.2 / JDK 17 / compare SDK 28. Интеграция адаптирует внутренний native-участник EDT и требует повторной проверки для другой SDK. Поддерживаются совпавшие табличные макеты с обеих сторон локальных workspace-проектов, до 2 MiB XML; бинарные MXL и односторонние добавления/удаления не охвачены. Обычное сравнение BSL сохраняет штатный маршрут.
