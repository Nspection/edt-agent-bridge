# EDT Agent Bridge 1.4.0.20261112zznativeflow4

Native execute/result получили краткие ответы по умолчанию, semantic wait, cursor pages и next_call исходного запроса. Полный прежний результат — details или compact=false, включая значения, null и ошибки. Снимки/сетка и команды исполнения сохранены; Native DLL и HostForm.bsl не менялись.

Плагин локально сопоставляет требуемую и имеющуюся Native/шаблон. Совпадение не вызывает сеть/пересоздание. Устаревание блокирует новую отправку и предлагает ensure_current/refresh_preview. Refresh проверяет владение, исходную SHA custom ZIP и незавершённые исходы; metadata требует явного разрешения FULL всем проектом. Журнал хранит исходные IDs, повтор не исполняет замену снова. Старая история и снимки доступны до отдельной уборки.

983 Java +74 Python-проверки, собственное и независимое ревью. В своей базе 8.5 наблюдение одного исходного запроса: full polling — 36 вызовов / 424966 байт, compact wait — 8 вызовов / 15403 байт. Это JSON-результаты без первоначального execute/discovery/envelope, не точный замер токенов. Проверены managed/custom refresh, null/full details, курсоры, неизвестный исход и сохранённые снимки. Пользовательскую EDT/базы не трогали.
