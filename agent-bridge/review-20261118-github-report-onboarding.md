# Проверка входа в GitHub для багрепортов

В тестовой копии EDT 2026.1.2.2 профиль P2 изначально не содержал Bridge. P2 director установил новую версию. SHA-256 установленных Core и UI совпали с файлами из проверенного P2-пакета. Для запуска SWT-проверки установленные JAR активировали в изолированной EDT через консоль Equinox, поскольку скопированный профиль EDT не обновил список запускаемых бандлов.

В новой рабочей области проверялись кнопки, вызов Git Credential Manager с параметром --browser, отдельная форма с защищённым полем, ссылка «Создать токен» и переход на форму нового Issue при отсутствии Git Credential Manager. Для проверки вызова GCM и адресов использовались локальные стенды. Вход с реальным аккаунтом и отправка Issue не выполнялись. Рабочая EDT пользователя и базы не участвовали.

Все семь этапов проверки артефактов прошли, включая 1426 Java-тестов. Независимая проверка сверила 13 относящихся к изменению классов с результатом компиляции и хеши P2-пакета и установленных JAR. Открытых замечаний по исходникам и артефактам нет.
