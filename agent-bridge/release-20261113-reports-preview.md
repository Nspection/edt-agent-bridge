# EDT Agent Bridge 1.4.0.20261113reports1

Добавлены технические багрепорты агентов через MCP в GitHub и проверяемое обновление native-предпросмотра уже открытой формы.

## Багрепорты

`edt_bug_report` предоставляет `prepare/status/submit/reconcile`. Пользователь один раз подключает GitHub через Git Credential Manager в настройках EDT и выбирает подтверждение каждого отчёта либо разрешение очищенной структурированной диагностики. По умолчанию отправка выключена. Отдельный сервер и общий токен в поставке не нужны.

Текст отчёта ограничен типизированной схемой; код, файлы, снимки, сырые сообщения/логи, пути и имена баз/проектов не поддерживаются. Перед отправкой проверяются точные bytes/hash, аккаунт, текущая политика, lifecycle и MCP exposure. Outbox сохраняет claim до POST, дедуплицирует одинаковые сбои и не повторяет неизвестную отправку. Монотонный CAS не позволяет позднему timeout потерять уже найденный Issue. Сеть не удерживает блокировку настроек. Полный HTTP exchange ограничен временем и размером ответа.

## Предпросмотр формы

`edt_editor_form_preview(mode=refresh|select, capture=true)` выполняет causal native rebuild без переключения Module/Form, сохранения или изменения исходников. Подтверждение привязано к авторитетной BM-модели, настоящему файлу `.form` и установленной новой native generation. Это работает и для редактора, восстановленного после перезапуска EDT, когда его input указывает на owner `.mdo`.

Обычный снимок формы не заявляет проверенную актуальность. Dirty editor сохраняется как есть; смена модели, файла, input, deadline или lifecycle даёт unverified. Внешние зависимости вроде `.dcssca` и визуальная правильность не входят в fingerprint. Внутренний SDK adapter ограничен проверенными версиями EDT.

## Исправление UI-run

Возобновление после подтверждения теперь владеет отдельной lease поколения job: поздний finally предыдущего запуска не может снять активность нового. Отказ очереди или записи resume не приводит к исполнению без сохранённого claim и не оставляет вечный active-флаг.

## Проверки и ограничения

1217 Java-тестов, 179 Python-тестов, 33 PowerShell-контракта контроллера, 3 CLI smoke и 13 startup-контрактов; OSGi visibility, границы standalone-поставки и source/artifact provenance. Собственное и независимое ревью выполнены; найденные замечания исправлены.

В собственной EDT проверены регистрация MCP, безопасный draft и запрет отправки при off, обновление двухстрочных заголовков без переключения вкладок и сценарий восстановленного редактора. Собственная форма восстановлена, свои процессы остановлены. Пользовательская EDT, базы и правки x5 не использовались.

Живой GitHub OAuth/POST от другого пользователя не выполнялся; доставка, таймауты и гонки проверены поддельным transport. Публичный тестовый Issue автоматически не создавался. Предыдущие исправления TestClient 8.3/Native из audit2 сохранены; живой прогон 8.3.27 этим релизом не добавлен.
