# EDT Agent Bridge 1.4.0.20261111zzupdates1

В настройках EDT Agent Bridge рядом с MCP добавлены «Проверить обновления» и «Обновить плагин…», установленная версия и результат проверки. Ручная проверка работает независимо от флажка автоматической проверки.

По умолчанию версия проверяется через 60 секунд после каждого запуска EDT и затем раз в сутки. Проверку можно отключить. О новой версии выдаётся немодальное уведомление без захвата фокуса, один раз на версию. Проверка ограничена официальным HTTPS manifest; ссылки установки из ответа не выполняются.

Установка запускается только по нажатию пользователя: native p2 готовит план только для Bridge и открывает штатный мастер. Автоматической установки/перезапуска нет; понижение версии не предлагается. Изменение только настроек обновления не перезапускает MCP-сервер.

Ревью и независимое ревью исправили race закрытия Display, оставлявший checking=true; старые lifecycle-ответы не показываются. 857 Java + 57 Python тестов, собственная EDT/SWT, native p2-план и verifyOnly прошли. Установка/завершение мастера не выполнялись. Базы не запускались, пользовательская среда не менялась.
