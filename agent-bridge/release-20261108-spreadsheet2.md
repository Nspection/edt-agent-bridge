# EDT Agent Bridge 1.4.0.20261108spreadsheet2

Табличные макеты MXLX теперь объединяются по свойствам native-модели EDT с общим предком: независимые изменения текста и оформления совмещаются, спорные свойства остаются конфликтами. Номера пулов оформления раскрываются в значения; native-сериализация сохраняет цвета и общие полосы колонок. Неоднозначные сдвиги и повторяющиеся блоки требуют явного решения.

Редактор показывает подсветку и таблицу различий, переходы, выбор текущего/источника и подтверждение ручного результата. Команды всего документа находятся в шапке вкладки; команды отличий — над их таблицей. Есть сброс, красный крестик с подтверждением и «Сохранить и вернуться к сравнению». Ручные правки сохраняются при пересчёте. Исправлены исчезновение шестерёнки и мигание таблицы.

MCP: semantic_diff, auto_merge, resolve_conflicts, reveal_difference, set_highlighting, ui_state, save_ui, reset_result в edt_merge_result. Запись требует актуального хеша; dirty-черновик и нерешённые конфликты защищены от применения. save_ui возвращает реальную ошибку без запроса пользователю закрыть диалог. Сохранение меняет план; исходники изменяются только после native apply.

Перед выпуском выполнены основное и два независимых ревью, все замечания исправлены. Проверки: 450 регрессионных Java-тестов, живой полный цикл в отдельной EDT, чтение/сохранение ручного ввода, ошибки сохранения/сброса, native apply и проверка итоговых файлов, локальный и публичный p2. Три использованных тестовых проекта, одноразовый проверочный модуль и тестовые записи запуска удалены после приёмки; базы для этого выпуска не создавались.

Совместимость: Windows x64, EDT 2026.1.2.2 / JDK 17 / compare SDK 28. Только поддерживаемые табличные ресурсы с обеих сторон workspace-сравнения, XML до 2 MiB; бинарный MXL и односторонние добавления/удаления не охвачены. API расширяет прежний общий план; обычное BSL-сравнение сохраняется.

[Описание команд и рабочего цикла](spreadsheet-merge.md). Обновление EDT: https://nspection.github.io/edt-agent-bridge/
