# Подготовка зависимостей

Реализованы отдельными выпусками:

- [Native](native-package.md): фоновая автозагрузка после запуска/обновления, SHA256, кеш, настройки и MCP.
- [Python](python-bootstrap.md): имеющийся CPython либо собственный официальный пакет, затем managed venv с hash-locked wheels; системный installer/PATH/реестр не меняются.
- [Vanessa](vanessa-bootstrap.md): проверенные EPF, VAExtension и client_mcp, настройки/MCP, автоматические artifact defaults профиля через наблюдаемое задание.

Пакеты не означают готовность базы или клиента. Создание отдельного менеджера, установка расширений и доверие остаются явными операциями согласованной тестовой среды; текущие инструменты подготовки/проверки сохранены. На этом этапе проверена пакетная подготовка/профиль, не заявлен новый полный Vanessa-сценарий.

Общие backend настройки/MCP дают агенту диагностику и повтор подготовки без ad hoc shell-окружений. Повреждённые/изменённые ресурсы сохраняются, неизвестная изменяющая операция не повторяется вслепую. Пользовательские EDT/базы в тестах не используются.
