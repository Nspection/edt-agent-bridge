Добавлены регрессии backend и orchestration для обоих сценариев. Остальные
проверки: начатый ответ не обрывается poll-дедлайном; общие5..300с согласованы
с wire/stdio/MCP; неподходящие бюджеты отклоняются до мутаций; общий бюджет
пакета не умножается неявно на число шагов; очередь orchestration не блокирует
свои вложенные preparation/action jobs. Без повторов изменяющих команд.

Предыдущая runtime-приёмка dev12 сохраняет силу для неизменённых клиента,
worker, сессии, budget и capture путей. Изменения двух review fixes локализованы
в UiRunBackend/UiRunService; сравнение JAR entries и807 тестов это проверяют.
Новые ошибки/исчезновение журнала проверены контрактами, не повреждением TMS.

Известные пределы: Windows/1С8.5.1.1522 и синтетические формы; не проверка
конкретной карты/ЦО TMS, произвольных контролов или серверной базы. Работа не
транзакционная. Default Python-cache verification имеет заметную стоимость;
новая диагностика её показывает, но не объявляет устранённой. Релиз/Pages
верифицируются отдельно по точному source commit и SHA256 после merge.
