# EDT Agent Bridge 1.4.0.20261117batch1

Исправлен ложный успех `edt_editor_capture_batch` при захвате управляемой формы: `captured=true` и `all_succeeded=true` больше не возвращаются для ответа без PNG.

- Активная страница формы захватывается через свежую native-проекцию. Модуль и остальные страницы сохраняют обычный маршрут snapshot.
- Успех требует существующего декодируемого PNG, корректных размеров и принятого результата; для native-формы проверяется projection freshness.
- Batch сохраняет причины отказа и подсказки следующего вызова. Смена вкладки до или во время capture отклоняет результат без повторного захвата.
- Ошибки alignment и cleanup учитываются отдельно. Ранее открытые редакторы сохраняются, новые закрываются только чистыми; сохранение и сброс правок не выполняются.

Native PNG содержит тело формы без панелей редактора; визуальная корректность требует осмотра изображения. SDK-ограничения прежние. Native DLL, протокол и шаблон обработки не менялись.
