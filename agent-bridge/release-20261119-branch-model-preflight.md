# EDT Agent Bridge 1.4.0.20261119zbranchmodel1

Перед обновлением инфобазы Bridge обновляет ресурсы проекта в Eclipse, ждёт завершения импорта и сверяет FQN из исходников с BM. При расхождении задание останавливается с причиной и списком FQN. Проверяются также вложенные подсистемы.

Перед FULL Bridge создаёт отдельный XML-экспорт штатным SDK EDT и сверяет его объявления с файлами. Штатное обновление по-прежнему выполняет EDT. Внутренний пакет, который reloadInfobase передаёт Конфигуратору, принадлежит SDK и недоступен Bridge через этот API.
