# EDT Agent Bridge 1.4.0.20261112zzzzzzzdialogs4

Прямой TestClient получил `dialog_inspect/dialog_answer` для уже обнаруженного прикладного подтверждения. MCP возвращает текст, точные доступные кнопки и варианты решения с готовыми вызовами; ответ требует явного разового разрешения на конкретные базу, исходную операцию, диалог и кнопку.

Ответ хранится отдельно и не повторяется новым ключом. Свежесть окна, текста и кнопок проверяется перед CLICK. Исходный неизвестный ввод не повторяется, mutation barrier остаётся. Вопросы безопасности, доверия, пароля и лицензии исключены; общий renderer и текстовый фильтр не заменяют семантическое решение пользователя.

Проверки: 1060 Java + 124 Python, своё и независимое ревью; собственная EDT и TMS_TEST_AGENT на 8.5.1.1522. В живом сценарии ответ «Да» закрывает предупреждение, но поле остаётся пустым: ввод не объявлен успешным. Финальный вариант «Нет», запреты повторного ответа, сохранение journal после stop и уборка также прошли.

Native DLL, host template и закреплённый vendor не менялись. Первоначальный transport timeout не объявлен исправленным. Время selecting_python измерено, оптимизация не входит в этот релиз.
