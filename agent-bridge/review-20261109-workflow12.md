# Ревью workflow12 — 09.11.2026

Основное ревью выполнено по actual diff относительно main cfd7137. Отдельный независимый агент read-only просмотрел реализацию и повторно проверил исправления; файлы, EDT и базы он не менял/не запускал. В итоговом заключении блокирующих замечаний не осталось.

Независимое ревью выявило два P1, исправленных до публикации:

1. Потеря ACK результата могла продолжить бизнес-шаги после ошибки или незаметно забрать следующее задание. Теперь terminal state фиксируется до сериализации/сети: пакет очищается, неизменяемый pending reply обслуживается до любого Poll. При неуспешной сериализации отправляется минимальная ошибка без values.
2. Исключение RPC после применения серверного шага могло повторить этот шаг. Теперь шаг локально помечается до RPC; исключение выполнения/разбора завершает пакет explicit outcome_unknown. Канал строго проверяет тип этого флага, запрещает success+unknown и сохраняет unknown при повторном чтении/перезапуске.

Проверены ownership и хеши уборки, различие legacy/external/metadata, generation-checked CF/XML proof, изоляция доступа/процессов, ограничения PNG и хранения, неизвестные исходы, очередь тяжёлых операций, bounded UI heartbeat. PrintWindow и runtime-границы описаны явно; сертификатом всех платформ и конфигураций результат не является.

675 Java-тестов и standalone boundary проходят. Живые проверки и искусственные потери ответов описаны в [валидации](validation-workflow12.md).
