# EDT Agent Bridge 1.4.0.20261117uimenu1

Добавлены открытие, чтение видимых пунктов, снимок и закрытие стандартного меню «⋮» через прямой TestClient Windows: `view=menu`, `menu_open`, `menu_close`. Распознанный диалог настройки формы/списка закрывается через `system_dialog_close` с привязкой к открывшей его операции и исходной форме.

Оконный backend задаётся явно. Проверяются PID/время запуска, окно, форма, владелец, поток и UIA identity; нет глобальной мыши, автоматического fallback или повторного нажатия. Основной результат сохраняется до необязательного снимка. Ошибка PNG не разрешает повтор операции.

Проверено через настоящий MCP на собственных одноразовых базах: 8.3.27.2325 и 8.5.1.1522, отдельный невидимый desktop. 1414 Java-тестов, 168 прямых TestClient Python-тестов и обязательные проверки продукта прошли. Собственное и независимое ревью завершены, собственные клиенты/базы/venv очищены, SDK остановлен. Пользовательские EDT, x5 и базы не использовались.

Границы: только верхний уровень стандартного меню и привязанные распознанные диалоги настройки. Подменю и произвольные системные/защитные диалоги не поддержаны этим контрактом; автоматического ответа «Да» нет. Видимость «Изменить форму» в меню не заявлена: в проверенных минимальных конфигурациях такого пункта не было. [Контракт](header-menu-dialogs.md).
