Ограничения: неподтверждённый вопрос безопасности запуска TestClient требует ручного решения; Windows может потребовать вручную активировать собственное окно перед ответом. Точный input ограничен живым вопросом/процессом и не отключает защиту платформы. Project Clean не удаляет .metadata или произвольный кеш и не обновляет ИБ.
