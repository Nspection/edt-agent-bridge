# EDT Agent Bridge 1.4.0.20261119zsdkstatus1

При FULL-обновлении Bridge обрабатывает предупреждения экспортера по правилам штатного обновления EDT. Bridge продолжает проверку XML-пакета. Обновление запускается только после проверки состава модели, объявлений и файлов.

При ошибке экспорта журнал и статус операции показывают сведения из Eclipse IStatus. Доступны уровень, модуль EDT, код, сообщения дочерних статусов и цепочка причин. Реквизиты в диагностике маскируются. Если EDT отменяет экспорт, Bridge отменяет операцию до обновления базы.
