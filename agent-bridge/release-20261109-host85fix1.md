# EDT Agent Bridge 1.4.0.20261109zzhost85fix1

Native host корректно подтверждает запуск и завершение команд, а уборка восстанавливается после частичного удаления внешнего проекта.

- Проверяются ответы Configure/Hello/Complete/Stop, в идентичности возвращается фактическое имя формы. Три последовательных сбоя останавливают канал; новые команды отклоняются.
- Уборка обнаруживает оставшуюся регистрацию проекта даже без файлов. Изменённые исходники сохраняются.
- cleanup_external_project удаляет только внешний проект. Metadata cleanup повторяет независимую проверку без лишнего FULL, если удаление уже синхронизировано; можно использовать живой verifier той же базы и подключения.
- FULL выполняет штатное отключение привязанной базы с сохранением настроек доступа под общей workflow-блокировкой.

Основное и независимое ревью завершены; 658 Java-тестов и standalone boundary пройдены. На 8.5.1.1522 подтверждены Native API внутри обработки конфигурации, клиентский/серверный вызовы и полная уборка. Подробности и границы приёмки — в отчёте проверок.

Известное ограничение: после перезапуска EDT может снова показать NOT_EQUAL после подтверждённого EQUAL перед перезапуском. Причина пока не установлена. Разрешения платформы не отключаются.

Актуальная EPF собирается через prepare; к выпуску приложен неизменённый проверенный Native ZIP. Статическая EPF прежнего выпуска не выдаётся за исправленную.
