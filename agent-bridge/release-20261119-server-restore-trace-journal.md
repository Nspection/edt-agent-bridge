# EDT Agent Bridge 1.4.0.20261119restoretrace1

Bridge ведёт локальный журнал при восстановлении существующей серверной ИБ из DT. Путь к restore-journal.jsonl доступен в progress.restore_journal. Журнал содержит этапы, время, длительность и итоговый код. Реквизиты, команды запуска и текст исключений в него не записываются.

При активной или непроверенной трассировке EDT статус показывает причину блокировки и этап, до которого дошло задание. Настройка EDT сохраняется. Если импорт подтверждён, статус указывает, что повторять его нельзя.

На отдельной серверной ИБ подтверждено, что штатный SDK EDT 2026.1.2.2 записывает тестовый пароль в аргументе /P. Bridge остановил операцию до резервного копирования и сохранил трассировку включённой. На стенде с выключенной трассировкой импорт и первый FULL завершились с EQUAL.
