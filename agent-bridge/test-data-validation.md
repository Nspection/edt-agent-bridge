# Проверка edt_test_data

Дата: 08.11.2026. Локальная сборка: `1.4.0.20261108testdata7`, ветка `codex/test-data-ledger`. Не опубликована.

Среда: отдельная EDT Agent Bridge Dev 2026.1.2.2, Java 17, новая собственная файловая база 1С 8.3.27.2325. Метаданные справочника и документа созданы фабрикой EDT; база создана и полностью обновлена штатным `edt_infobase_provision` (native `reloadInfobase`, EQUAL). Host в режиме external, исполняемый рецепт — серверный BSL.

| Проверка | Результат |
|---|---|
| Создание элемента справочника | UUID/версия подтверждены, независимое чтение наименования |
| Создание документа с типизированной датой | Дата совпала; Проведен=false |

| Закрытие журнала | Не заявляет удаление базы или записей |
| Финальный кандидат после запрета каскадной пометки | Повторное создание и пометка обоих типов прошли |
| Java-регрессии и границы пакета | 497 тестов, PASS |

Наименование тестового справочника имеет стандартную длину 25: платформа обрезает длинное значение. В проверке сравнивается фактически записанное значение; подтверждение создания не обещает сохранение каждого входного символа без преобразования приложением.

Исправлено по ревью: для справочников пометка подчинённых явно отключена вторым аргументом Ложь; Windows-очистка временных тестовых каталогов закрывает обход перед удалением и допускает короткий повтор при отложенном освобождении файлов.

Подмена квитанции, потеря ответа, чужая база, предопределённые/проведённые объекты и уже отсутствующие ссылки проверены модульно; живое покрытие этих веток не заявляется. База файловая, это не проверка кластера, 8.5 или бизнес-обработчиков x5. Пометка удаления не является физическим удалением, прикладные побочные эффекты отдельно не отслеживаются.

Локальные подробные доказательства и фактическая уборка: `.runs/test-data-live/state.json`, `test7.log`, `cleanup.json`. Эти файлы не входят в Git. Собственные временные host и тестовый проект убраны; удаление базы, регистраций и доверия проверяется отдельно в cleanup.json.
