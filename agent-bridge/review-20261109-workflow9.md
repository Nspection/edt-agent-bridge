# Ревью workflow9 — 09.11.2026

Основное ревью и независимый read-only проход завершены. Исправлены четыре замечания:

1. Подключённая изменённая база: native connect может вернуть already connected. Принимается только точный name-specific IllegalArgumentException с native SDK-кадром infobaseConnected; ошибки транспорта/доступа остаются ошибками. EQUAL после обновления обязателен.
2. MCP-порт менеджера: общая аренда порта между прогонами, проверка свободного TCP-порта и PID слушателя. Чужой endpoint не используется.
3. Старые файловые run receipts: ограниченная совместимость только при совпадении проекта, UUID, реального пути и прежнего хеша. Новая схема маркируется connection-v1; серверный fallback отсутствует.
4. Ошибка готовности менеджера: собственные процессы останавливаются; Status сохраняет RunId для безопасной остановки без воздействия на чужие процессы.

Независимый ревьюер повторно проверил исправления и не обнаружил блокеров. Он не запускал EDT лично. Проверки исполнителя: 572 Java-теста, 29 контрактов PowerShell, компиляция 613 production-файлов; два реальных запуска Vanessa и отдельная проверка уборки (см. task-vanessa-live-validation.md).

Ограничения: native guard проверен на EDT 2026.1.2.2; изменение SDK может потребовать адаптации и приведёт к явному отказу. Живой прогон не подтверждает все версии EDT, серверные ИБ и прикладную логику x5. Открытый MCP-порт не удостоверяет личность произвольного TestClient.
