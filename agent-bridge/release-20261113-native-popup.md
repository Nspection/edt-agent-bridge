# EDT Agent Bridge 1.4.0.20261113popup1

Native сохраняет исчезающие popup сразу при их появлении: наблюдение включается до BSL, собственные окна совмещаются по координатам и кадр остаётся доступным после закрытия меню. При `screenshot_expect=popup` отсутствие popup возвращает ошибку захвата, сохраняя исход выполненного шага. Повтор кода для скриншота не выполняется.

Новые Native-клиенты работают на отдельном невидимом desktop Windows. Пользовательский desktop не переключается, автоматического видимого fallback нет. Старые host сохраняют режим; для интерактивной настройки доверия visible выбирается явно, затем можно остановить и перезапустить isolated. Startup input на isolated desktop пока недоступен. TestClient этим режимом не меняется.

Пересобраны Native ZIP/DLL и AgentHost.epf из текущего шаблона, обновлены SHA256 и capabilities; IDs прежних Native API сохранены. Квитанции сохраняют происхождение и реальное время кадра в компактном и восстановленном ответе.

1263 Java, 179 Python, 33 controller +3 CLI +13 startup проверок, OSGi/boundary/provenance и p2 verifyOnly. Реальные меню 1С 8.3.27.2325 и 8.5.1.1522 проверены в собственной среде; actual-DLL тест проверил снимок уже закрытого popup. Собственное и независимое Astra medium ревью завершены, открытых подтверждённых P1/P2 нет. Пользовательская EDT, базы и x5 не изменялись.
