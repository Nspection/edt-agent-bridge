# EDT Agent Bridge 1.4.0.20261110zzzpyenv1

Одна команда `edt_test_client action=prepare_environment` находит подходящий Python, создаёт отдельную среду с закреплёнными версиями и SHA256 пакетов и переиспользует готовую. После этого запуск собственного TestClient не требует python_path. Сохранённый явный путь по-прежнему поддерживается.

- Статус готовности проверяет файлы, версии, imports и привязку к workspace; повторная подготовка не запускает pip заново.
- Короткий workspace-кеш в LocalAppData избегает Windows MAX_PATH. Среда не смешивается с глобальным Python или другим workspace.
- Уборка запрещена для занятой/изменённой среды. Проверка и запуск держат lease; удаляются только записанные собственные файлы.
- Основное и независимое ревью завершены. Неизвестный исход установщика теперь сохраняется как interrupted без автоматического удаления; AMD64 проверяется до установки.

702 Java-теста,23 Python-контракта, собственная runtime-проверка на Windows/CPython3.13/1C8.5.1.1522 и p2 verifyOnly на отдельном профиле. Пользовательская EDT и базы не использовались, собственные тестовые ресурсы убраны.

Требуется установленный стандартный CPython3.11–3.14 Windows AMD64 с venv/ensurepip. Команда не устанавливает базовый Python. Первый запуск подготовки скачивает только разрешённые wheels с PyPI; зависшая/прерванная установка сохраняется для разбора. Прежний маршрут Vanessa и ограничения прямых таблиц сохранены.
