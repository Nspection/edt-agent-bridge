# Редакторы: список, закрытие и пакет снимков

Доступно с `1.4.0.20261109zeditors1`; проверять `edt_capabilities` установленной версии. В workflow9 этих команд ещё нет.

- edt_editor_list: верхние редакторы активной страницы workbench без активации/восстановления. editor_id выдаётся для загруженных редакторов. Внутренние страницы объекта/формы перечисляет edt_editor_tabs.
- edt_editor_close(editor_id): закрывает сохранённый редактор штатным IWorkbenchPage.closeEditor. dirty_editor оставляет его открытым без сохранения или отбрасывания правок. closed=true подтверждается отсутствием редактора в native references; close_refused не является успехом. В ответе оставшиеся editors.
- edt_editor_capture_batch(items): от 1 до 8 заданий последовательно проходят существующие native open → select/snapshot → close. Возвращает один results с компактными PNG-описаниями и статусами каждого задания, all_succeeded и remaining_editors. Только новые чистые редакторы закрываются. Ранее открытые сохраняются, выбранная внутренняя страница восстанавливается. Ошибка одного файла не прекращает остальные; ошибка уборки явно возвращается.

```json
{"items":[
 {"project":"MyProject","file_path":"Catalogs/Items/Items.mdo","tab_title":"Основные"},
 {"project":"MyProject","file_path":"Catalogs/Items/Forms/Item/Form.form","tab_title":"Форма"}
]}
```

Для восьми объектов передать восемь элементов items; результаты приходят одним ответом после обработки всего пакета. Один элемент снимает одну внутреннюю вкладку. Для страниц внутри preview формы остаётся edt_editor_gallery, для прокрутки — edt_editor_scroll. Ни снимок, ни all_succeeded не подтверждают корректность оформления: агент должен просмотреть PNG. Используется текущий размер окна/области редактора; снимок не означает полный длинный документ.

Сохранить edt_editor_list до обычной ручной последовательности open/snapshot, затем закрывать только свои новые IDs. Сам список не доказывает владение. Нет close-all, автосохранения или принудительного discard. Модальные окна остаются блокером и не подтверждаются автоматически.

Проверено в отдельной EDT 2026.1.2.2: пакет 8 native-редакторов справочников, сохранение ранее открытого редактора, закрытие семи новых, смешанный пакет с отсутствующим файлом и успешным следующим, явное закрытие и восстановление исходного набора editor IDs. dirty_editor проверен регрессионным тестом без вызова native close. Тестовый проект удалён, базы для этой проверки не создавались.

Если после native open не удалось прочитать страницы редактора, инструмент убирает только новый чистый редактор и возвращает сведения об уборке. Ошибка финального списка вкладок возвращается отдельно в remaining_editors_error: уже полученные PNG и результаты не теряются.
