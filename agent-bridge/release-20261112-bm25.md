# EDT Agent Bridge 1.4.0.20261112zzzzbm251

Добавлен searchType=bm25 в существующий edt_search_in_code: ранжирование методов BSL по нескольким словам, именам объектов, синонимам и комментариям; top_k, точные строки, matched_terms и короткие фрагменты. Прежние text/regex сохранены, новых компактных инструментов нет.

Индекс локальный, инкрементальный и ограниченный по ресурсам; холодные запросы работают в отдельной фоновой очереди с next_call к исходному job. Учтены ветки/worktree, удаления/переименования, актуальность выбранных файлов и явная неполнота. Нет облачной модели, Python, запуска/обновления базы.

1026 Java-тестов, собственное и независимое ревью, отдельная OSGi/EDT-проверка на копии TMS. На 26 независимых запросах известный метод найден в top5 у 17 запросов против 6 у прежнего поиска. Это ограниченный lexical benchmark, не гарантия поиска по смыслу и не точный замер токенов.
