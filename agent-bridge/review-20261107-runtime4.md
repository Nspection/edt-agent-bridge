## Исправления

1. HTTP читал всё тело запроса без верхней границы. Теперь принимается не более 16 MiB, включая chunked-запросы; превышение возвращает HTTP 413 до вызова инструмента.
2. Пул HTTP-потоков не принадлежал lifecycle транспорта, а SSE heartbeat мог переживать stop. Теперь пул ограничен 16 workers/64 queued tasks, потоки daemon, stop закрывает executor и активные SSE; повторный start создаёт новый executor. Обычные HTTP exchanges закрываются после ответа. При заполнении очереди транспорт может отклонить соединение; автоматически повторять неизвестную изменяющую операцию нельзя.
3. Нераспознанная команда попадала в GSD-disabled guard. Теперь сначала проверяются экспозиция и регистрация; неизвестное имя возвращает Unknown tool, отключённая зарегистрированная возможность по-прежнему не исполняется.
4. Worker Vanessa перехватывал Exception, но не LinkageError из EDT SDK. Теперь обычная ошибка совместимости завершает прогон как failed/cleanup_failed и выполняет существующую уборку. Fatal VM errors не маскируются.
5. Статус passed принимался при Report.Failures/Errors > 0. Такой противоречивый отчёт теперь отклоняется и собственный прогон закрывается.
6. Контрактные тесты оставляли каталоги. Для Java fixture добавлено удаление после остановки worker и ограниченный повтор удаления каталогов при pending-delete Windows; PowerShell fixture убирается в finally только по проверенному собственному пути.

## Проверки и пределы

415 Java-тестов и 24 PowerShell-контракта Vanessa прошли. Постоянный набор расширен 14 группами тестов MCP, схем, registry, file/tool contracts. Старые проверки OAuth и профилей приведены к standalone Bearer-only продукту, без возврата удалённых функций.

Живая проверка в отдельной EDT 2026.1.2.2 / Java 17: runtime4 загружен, все 133 схемы получены с пагинацией и проверены, имена уникальны, неизвестная команда отвергнута, MCP-сессия удалена. Dev EDT затем закрыта. Новых проектов, баз, записей запуска, правил доверия или процессов 1С не создавалось. Рабочая TMS EDT пользователя не менялась.

Полный цикл с 1С/Vanessa/DT, серверный кластер, 8.5, Linux и web-клиент в этой ревизии не запускались. Успех этого ревью не заменяет прикладную приёмку конкретной конфигурации.
