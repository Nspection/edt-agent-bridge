# Актуальность native-предпросмотра формы

`edt_editor_form_preview(mode=refresh|select, capture=true)` обновляет текущую чистую форму native-рендерером EDT и связывает снимок с завершившейся генерацией. Переключение Module → Form, повторное открытие, сохранение и изменение формы для этого не нужны.

`editor_ready` означает готовность вкладок. `ready=true` у form preview означает совпадение авторитетной BM-модели, модели редактора, ревизии файла и установленной новой native generation. Обычный `edt_editor_snapshot` формы по-прежнему создаёт изображение, но возвращает `ready=false` и `freshness_call`; одна задержка не доказывает актуальность изображения.

`projection_freshness.model_sha256` можно передать как `expected_model_sha256` следующему вызову. Fingerprint охватывает containment модели Form и URI ссылок. Содержимое внешних зависимостей, включая `.dcssca`, не проверяется; `external_dependency_contents_verified=false`. Готовая генерация не доказывает визуальную корректность — снимок следует осмотреть.

Защиты: dirty editor не сохраняется и не сбрасывается; смена editor/input/model, lifecycle epoch или source revision отменяет подтверждение; reader имеет ограниченный pool и общий 30-секундный бюджет с UI-очередью. После таймаута поздний callback не рендерит. Native completion adapter проверяет точные версии SDK presentation `16.0.2.v202607090722` и layout `15.0.1.v202607090722`; неизвестный SDK возвращает unverified. Это явно ограниченный адаптер к внутреннему API, который требует повторной проверки при обновлении EDT.

Приёмка в собственной изолированной EDT: уже открытая чистая форма, внешнее изменение двух заголовков с LF/autoWidthInTable None и headerHeight=2, refresh без переключения вкладок, совпадающие BM/editor hashes и осмотр двухстрочных заголовков. Исходная собственная форма восстановлена байт-в-байт. Пользовательская EDT и базы не использовались.
