# EDT Agent Bridge 1.4.0.20261112zzzzzcontext1

Добавлен opt-in searchType=auto в существующий поиск: идентификаторы ищутся буквальной подстрокой, предметные формулировки ранжируются BM25. Отсутствующий searchType по-прежнему означает text; явные text/regex сохраняют формат, порядок, совпадения и прежние ограничения. Компактный top_k относится только к auto/BM25.

bsl_get_method_body получил items1..8 с общим max_chars и отдельными ошибками/усечением. Одиночное чтение сохранено. Медленный пакет после20с возвращает job_id/next_call; отдельная очередь не занимает обычные background workers. Исходники и ИБ не изменяются.

1050 regression-тестов и standalone boundary, собственное и независимое ревью. В собственной EDT проверены18 полных legacy JSON-ответов против предыдущего релиза и семантическое чтение настоящего модуля. Сравнение маршрутов и границы доказательств описаны отдельно; logical call counts не равны расходам LLM.
