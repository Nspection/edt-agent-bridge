# EDT Agent Bridge 1.4.0.20261111zzzzzflow1

UI и runtime preparation поддерживают observation-only wait с готовыми next_call. Краткие ответы сохраняют исход, этап, причины, ID и счётчики шагов; details возвращает подробности. Unknown/failed не повторяются автоматически, ready проверяется актуально.

Добавлены baseline/changes существующих метрик, корректные имена компактных операций и отдельный учёт запросов контрактов. Baselines ограничены16/1час и теряются при рестарте; payload/токены не сохраняются.

Ревью и независимый probe исправили потерю runner_profile_missing. 902 Java +57 Python-проверок прошли. В своей EDT с тонким клиентом проверены создание, ввод, сохранение и проверка списка; один сценарий сократился с3 до2 вызовов и с4206 до2330 байт JSON результатов. Это не замер токенов или общее ускорение. Пользовательская EDT/базы не использовались, свои ресурсы убраны.
