# EDT Agent Bridge 1.4.0.20261109zworkflow10

Агенту проще проверить результат своей работы и продолжить её после перезапуска EDT. Пошаговые команды сохранены.

- Проверка живого TestClient подтверждает, что действия Vanessa попадут в базу выбранного проекта. Новая task-session требует verify_client перед UI-шагами.
- edt_data_assert проверяет несколько условий по данным одним запросом и возвращает короткий итог с причинами несовпадений.
- edt_form_state умеет отдавать изменения относительно предыдущего снимка формы с сохранением порядка и повторов строк.
- edt_merge_checkpoint сохраняет план, ручные результаты макетов/BSL и вопросы ИИ между запусками EDT. Восстановленный макет можно штатно применить.

Новое сравнение пользователя остаётся новым: старый checkpoint не восстанавливается автоматически. Замена текущего плана требует отдельного явного действия и совпадения исходников.

В основном и независимом ревью исправлены гонки проверки клиента/плана, применение восстановленного макета, передача null и статус неизвестного исхода. 620 Java-тестов, настоящая Vanessa, native 1С и restore → native apply проверены в отдельной EDT. Тестовые базы и проекты убраны.
