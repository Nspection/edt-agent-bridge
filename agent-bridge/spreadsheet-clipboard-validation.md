# Буфер обмена в табличном объединении — 09.11.2026

Исправлено в `1.4.0.20261109zeditors1`.

Причина недоступных Copy/Paste: внешний MultiPageEditorPart не предоставлял активный MoxelEditor штатным обработчикам EDT и не активировал их контекст. Теперь он адаптируется к вложенной странице и использует scoped native Moxel context. Undo/Redo привязаны к истории результата; на исходных страницах изменения запрещены, копирование разрешено. При закрытии контекст и обработчики освобождаются.

Вход и выход из редактирования текста внутри ячейки обновляют состояние команд по событиям native-контрола. Защитные обработчики целых ячеек снимаются на время inplace и заново устанавливаются после выхода. Таймеров перерисовки для этого нет.

Штатный бинарный буфер EDT теряет непустой нейтральный текст с ключом `#`. Copy/Cut такого выделения теперь прекращаются **до изменения буфера или документа**, с объяснением. Это защитный отказ, а не исправленный сериализатор EDT. Можно выбрать сторону объединения или отредактировать результат вручную. Собственный формат буфера/алгоритм вставки не добавлен.

Проверено в отдельной EDT 2026.1.2.2:

- нейтральный `#` блокируется до native Copy;
- диапазон двух строк с текстом `ru` и жирным шрифтом скопирован штатными командами IHandlerService из readonly источника в результат; значения и оформление сохранены;
- Undo возвращает точный XML черновика, Redo восстанавливает вставку;
- внутри inplace защитный обработчик ячеек отсутствует, native Text.copy копирует выделенный текст; после выхода команда Copy снова копирует значение ячейки;
- save_ui сохраняет черновик в native-план, оба исходных файла не меняются при сохранении; PNG результата просмотрен.

Границы проверки: физические Ctrl+C/Ctrl+V не имитировались. В скрытом Text маршрут IHandlerService возвращал NotHandled из-за отсутствующего фокуса: для inplace подтверждён native-виджет Text.copy, а не клавиатурный путь. Native Cut для отдельных ячеек показывает штатный диалог сдвига, который автоматически не подтверждался; его полный сценарий не заявлен проверенным.

579 Java-тестов и 29 PowerShell-контрактов проходят; production-сборка — 617 файлов. Проба использовалась только в отдельной EDT, не входит в продукт и удалена из конфигурации. Два проекта проверки буфера и один проект пакета редакторов, их регистрации, снимки в workspace и временные каталоги удалены. Базы не создавались. Пользовательская EDT не перезапускалась.
