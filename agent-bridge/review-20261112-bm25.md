# Ревью и приёмка BM25

1.4.0.20261112zzzzbm251. Собственное и независимое ревью, открытых подтверждённых P1/P2 нет. Независимый harness воспроизвёл и затем подтвердил исправления: мёртвый словарь при rebuild/замене корпуса; постоянная холодная индексация Git worktree; неограниченное имя метода в malformed BSL. Потенциальное занятие общего executor устранено отдельной bounded search-очередью и подтверждено отдельным harness. Проверены coalescing/continuation/лимит ожидающих jobs и выполнение обычного фонового задания во время BM25.

1026 Java regression-тестов и standalone product boundary прошли. В одном предыдущем повторе unrelated OwnedFileBaseServiceTest получил Windows DirectoryNotEmptyException в собственной leases-фикстуре; финальный последовательный прогон с низким приоритетом прошёл полностью. В первых новых тестах исправлены неверные ожидания OR-поиска с общим словом и нормализация мягкого знака; временная уборка усилена только у новой BM25-фикстуры. Существующий сервис файловых баз не менялся.

Отдельная headless OSGi/EDT-конфигурация, собственный workspace и копия TMS: edt_search_in_code cold→job_id/next_call→edt_operation_status→результат, тёплый запрос updated_files=0, новый собственный BSL-файл updated_files=1, прежние text/regex нашли тот же контрольный маркер. Проверено исполнение обычного job во время холодного BM25. Временный файл удалён, проект снят с регистрации, .project копии восстановлен побайтно. Это проверка инструмента в OSGi, не полный анализ модели TMS и не измерение интерактивной SWT-задержки пользовательского workbench.

Сравнение с text и сильным OR-regex — по 26 заранее зафиксированным независимым вопросам, без публикации пользовательского кода. [Метрики и ограничения](benchmark-20261112-bm25.md). Приёмка отражает partial одного документа и не выдаёт lexical BM25 за semantic embeddings.

Копия тестового корпуса хранится вне наблюдаемого EGit репозитория. Финальные тяжёлые прогоны выполнялись последовательно с пониженным приоритетом. Интерактивная SWT-задержка не измерялась; снижение конкуренции за ресурсы не является доказательством отсутствия UI-задержек.

Native, BSL-шаблон host, worker TestClient и протоколы не изменены. Публикация включает p2 verifyOnly на отдельной копии профиля, сверку merged classes с проверенным кандидатом и проверку обычного публичного update URL/SHA256/p2 resolver. Доказательства — .runs/release-bm25/.
