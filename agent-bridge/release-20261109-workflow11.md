# EDT Agent Bridge 1.4.0.20261109zworkflow11

Агент тратит меньше обменов на поиск команд, ожидание и продолжение задачи. Пошаговые инструменты сохранены.

- edt_capabilities выдаёт несколько схем за вызов; маршруты запрашиваются явно, каталог проверяется по хешу.
- edt_ready ждёт нужные команды и выбранную модель без запуска/обновления базы. SDK container не выдаётся за подтверждённое соединение выбранной ИБ.
- edt_operation_status умеет ждать завершения и возвращать короткий итог с ID.
- Общий response выбирает объём ответа; edt_result читает пропущенные детали без повторного исполнения.
- edt_task_batch объединяет до 16 проверяемых шагов с durable keys и остановкой при ошибке/неизвестном исходе; task_session resume восстанавливает записанный контекст.
- edt_agent_metrics показывает вызовы, байты и время без хранения payload.

Основное и независимое ревью завершены, замечания исправлены и перепроверены. 652 Java-теста, 29 контрактов Vanessa; runtime и restart проверены в отдельной EDT. В контрольном discovery-сценарии: 3→1 вызов, 10 688→2 847 байт. Это не измерение фактических токенов модели.
