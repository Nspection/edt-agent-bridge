# Свойства создаваемых команд и командные модули

С `1.4.0.20261117vcommands1` свойства `add_metadata_child(child_kind=Command)` применяются после штатного создания EDT и инициализации ссылок. Используется тот же типизированный механизм, что в `update_metadata`, в одной BM-транзакции. Поддерживаются одиночное создание и параметры каждого элемента `properties.children`.

```json
{"project":"OwnProject","parent_fqn":"Catalog.Owner","child_kind":"Command","name":"Run","properties":{"group":"FormNavigationPanelImportant","commandParameterType":{"types":["CatalogRef.Owner"]},"representation":"Auto"}}
```

Как и раньше, перед изменением нужен `edt_validate_request` и его одноразовый token. Ссылочные типы предварительно разрешаются в контексте проекта, стандартная группа берётся из ресурса платформы EDT. Отсутствующие свойства сохраняют native defaults. Неизвестное свойство, неразрешённая группа или тип завершают операцию ошибкой; неверное свойство второго элемента откатывает весь пакет. Имя, синоним и комментарий задаются общими аргументами создания, UUID назначает EDT.

Для `ensure_module_artifact(object_fqn=Catalog.Owner.Command.Run)` значения `module_kind=auto|module|command` указывают на один файл:

```text
src/Catalogs/Owner/Commands/Run/CommandModule.bsl
```

Файл `Module.bsl` в каталоге владельца не удовлетворяет этому запросу. При `create_if_missing=false` отсутствующий командный модуль возвращает ошибку, даже если модуль владельца существует. При создании используется правильный каталог команды; существующий командный модуль не перезаписывается `initial_content`. `object` и `manager` для Command отклоняются до файловых действий. Для CommonCommand общий псевдоним `module` также выбирает `CommandModule.bsl`; пути форм и CommonModule сохранены.

Проверено через настоящий MCP в отдельной собственной EDT 2026.1.2.2 с проектом 8.5.1: экспорт, холодное перечитывание, native BM-ссылки, rollback и сохранность модулей. Информационная база и клиент не создавались. Приёмка исполнения прикладного обработчика команды этим не заявляется.
