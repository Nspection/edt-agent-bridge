# Ревью Vanessa bootstrap

Diff относительно 5a1507d просмотрен собственным и независимым ревью: три закреплённых upstream artifact, SHA256 ZIP/EPF/CFE, безопасные raw/ZIP generations, shared settings/MCP backend, предварительная валидация профиля, async write, singleflight, CAS и отсутствие скрытого изменения баз/доверия.

Независимое ревью воспроизвело два P2. Первый: холодный синхронный put мог превысить120s MCP timeout и позднее сохранить профиль без наблюдаемого job. Исправлен единым фоновым заданием для загрузки и записи, немедленным job_id/next_call. Второй: explicit put мог обойти active guard и быть затёрт старым заданием. Все explicit/default записи разделяют guard; дополнительно перед commit проверяется исходный stateHash файла, поэтому внешнее изменение сохраняется. DeferredJobs-регрессии проверяют отсутствие синхронной записи/загрузки, dedup, changed request busy и обе гонки.

Итог: 941 Java +41 worker +16 table тестов. Независимый отдельный harness актуальных классов:12/12 PASS; открытых P1/P2 нет. Промежуточный dev3 suite имел один сбой удаления пустого временного каталога SnapshotAlignmentTest на Windows; product-assertions не падали, следующий полный dev4 прогон941PASS. Остаток того временного каталога удалён.

В своей EDT cold put вернул job за0.044s, активный повтор вернул тот же ID; три официальных хеша, кеш после рестарта и финальный guarded/explicit put проверены. Профиль использовал placeholder-пути баз; менеджер/1С/расширения/доверие/бизнес-сценарий не запускались. Свои пакетные файлы, профиль и fixture убираются, private конфигурация восстанавливается. Публикация проверяется merged JAR equivalence, p2 resolver, GitHub SHA256 и обычным URL.
