# Проверка типизированных элементов TestClient — 12.11.2026

Кандидат: `1.4.0.20261112zzzzzzcontrols4`. Windows x64, платформа 8.5.1.1522. Проверки проведены в отдельной EDT с собственными workspace/configuration/MCP; пользовательские EDT и базы не запускались и не изменялись.

## Реализация и ревью

Добавлены типизированные действия поверх прежнего прямого TestClient без нового MCP-инструмента. Сохранены обычные input/button/table, Native DLL, протокол и шаблон Native host. `potential_actions` означает возможности типа, а не готовность элемента.

Собственное и независимое ревью выявили и устранили: неточный фокус, смену формы перед переключением, неверный verified-флаг при неуспехе, смену строки перед флажком и лишний второй обход дерева для обычной кнопки. Независимый повторный probe подтверждает один обход для input, Button command и Decoration command. Открытых подтверждённых P1/P2 нет.

Полный регресс: **1057 Java + 106 Python** (65 worker, 19 table, 22 controls), проверка границы standalone-продукта. Локальная p2-проверка обновления на копии профиля в verifyOnly успешна.

## Runtime

На собственной мини-конфигурации: check/uncheck тумблера, no-op уже установленного флажка, radio/выпадающий список с точным выбором, spinner, slider с проверкой отображаемого значения, календарь с отдельным связанным полем даты, переключение страниц, команды групп, label handler с отдельным штатным диалогом, обычная кнопка, модальная форма, булевы ячейки и смешанное добавление text/bool. Скрытые, readonly и disabled поля отклонены до изменения.

Финальный controls4 повторил кнопку, тумблер, radio/dropdown, spinner, slider, calendar, page и table boolean. Модальное окно прочитано и закрыто после PrintWindow; затем **100 последовательных чтений за 10,78 с** без потери канала. Это ограниченный smoke, а не доказательство отсутствия всех таймаутов больших TMS-форм.

В собственной новой **TMS_TEST_AGENT** пройден начальный запуск: регион ru, Europe/Moscow, корпоративная поставка. Native отдельно прочитал сохранённые ru/КОРП. Через Native создана одна явно отмеченная запись «ТЕСТ ИИ 20261112» справочника ЯзыкиМира; это проверка BSL/данных, не успешное сохранение через TestClient.

Встроенный Native Screenshot и следующая серверная команда успешно выполнены в TMS_TEST_AGENT и мини-базе; PNG и сетка сохранены и проверены. На controls4 пакет повторён успешно. Native DLL и шаблон не менялись. Старые сообщения Screenshot/queue/120-секундного TC preflight timeout в этих условиях не воспроизведены и не объявлены исправленными.

## Ограничения

Календарь не поддерживает обычный scalar getter на проверенной 8.5: дата проверяется через отдельное связанное поле. Первый тест ожидал дату без времени и честно завершился condition_timeout; чтение подтвердило установленную дату со временем, повторного изменения не было. Финальный точный формат прошёл.

Пустая таблица возвращает table_rows_unproven без ввода данных. Непустая таблица прошла bool on/off, добавление и точный итог двух строк.

TMS-подтверждение «Редактирование поля Наименование не рекомендуется» во время input вернуло complete-negative action: канал пригоден к наблюдению, исход неизвестен, новые мутации блокируются. Запрос не повторялся; исходный результат и диалог сохранены, Native подтвердил отсутствие записи. Автоматический ответ/восстановление этой операции не входит в релиз. Самостоятельные позднейшие BSL-данные отмечены отдельно.

Rich HTML/документы/диаграммы не объявлены редактируемыми. Сложные прикладные подтверждения и исходный производственный timeout остаются отдельной диагностической работой. См. [контракт элементов](direct-testclient-controls.md).

## Уборка

Все собственные TestClient и Native-клиенты закрыты, внешняя EPF и внешние проекты убраны. Для каждого metadata host подтверждены cleaned=true, source_removed=true, database_verified_absent=true. Одноразовая мини-база и проект удалены штатными командами по lease/маркеру: database_removed=true, cleanup_verified=true, launcher_record_removed=true, removed=true. Собственная EDT остановлена после проверки. TMS_TEST_AGENT с одной явно отмеченной записью и её копия проекта сохраняются как разрешённая собственная среда дальнейших проверок; они не являются пользовательской TMS_FILE85.
