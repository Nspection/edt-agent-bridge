# EDT Agent Bridge 1.4.0.20261108workflow8

Агенту проще вести задачу от выбранной базы до проверки результата и уборки: окружение сохраняется один раз, каждый шаг можно проверить, ожидание возвращает только новые события или изменения формы. Все прежние пошаговые команды доступны.

- `edt_task_session`: сохранённая привязка проекта, приложения и runner-профиля, инвентарь собственных ресурсов.
- `edt_task_step`: один шаг с защитой повторов и явной проверкой текстового результата формы.
- `edt_task_wait`: ожидание событий прогона, собственного задания, условия или изменения формы.
- `edt_check(action=receipt)` и отчёт: сопоставление исходников с контрольными точками прогона.
- `edt_task_cleanup`: проверяемый план уборки зарегистрированных ресурсов. `edt_infobase_cleanup` удаляет только новую файловую базу, заранее созданную с disposable_test_base=true, через native EDT teardown и защищённый quarantine.

Основное и повторное независимое ревью: исправлены семь дефектов, в том числе преждевременный успех асинхронного шага, ложная пустота сообщений и возобновление уборки. 565 Java-тестов и границы standalone-продукта прошли; p2 проверяется штатным механизмом в отдельном профиле.

В собственной EDT проверены настоящие создание/FULL-обновление/уборка файловой базы и HTTP MCP. Для UI применён сервер Vanessa-протокола: это не новая приёмка на настоящем TestClient. Серверные базы не получают автоматического физического удаления; деловые записи убираются только существующим mark_deletion. Свои тестовые проекты, базы и записи запуска удалены; рабочая EDT пользователя не менялась.
