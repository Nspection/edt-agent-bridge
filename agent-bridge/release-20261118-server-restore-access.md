# EDT Agent Bridge 1.4.0.20261118zserver5

Серверное восстановление DT использует сохранённый доступ EDT для резервной копии строго выбранной зарегистрированной ИБ. Если EDT запрашивает доступ, статус исходного задания показывает этап и доступные действия. Реквизиты можно ввести в нативном окне EDT либо в защищённой форме Bridge. MCP получает только одноразовый идентификатор запроса из исходной сессии.

Вход в старую базу и вход после импорта DT имеют разные этапы. Новые реквизиты можно проверить после импорта и, с отдельного согласия на сохранение, использовать для первого FULL-обновления. Резервная копия обязательна. При неизвестном исходе импорта Bridge сохраняет блокировку новой попытки.

На изолированной серверной ИБ 1С 8.3.27.2325 проверены смена пользователя в DT, ввод новых реквизитов, первый FULL с `EQUAL`, отказ чужой сессии и отмена запроса устаревшего доступа до импорта. [Подробности проверки](review-20261118-server-restore-access.md).
