# EDT Agent Bridge 1.4.0.20261109zeditors1

Агент может получить список вкладок, безопасно закрыть свои сохранённые редакторы и одним пакетом снять до восьми объектов: открыть → выбрать страницу → PNG → закрыть новые чистые редакторы. Несохранённые и ранее открытые вкладки сохраняются. Результаты успешных элементов не теряются при частичном отказе.

В табличном объединении подключены штатные Copy/Paste и история Undo/Redo текущего результата. Исходные страницы остаются readonly. После редактирования текста внутри ячейки команды снова переключаются на ячейки. Опасное копирование нейтрального текста `#`, который теряет буфер EDT, блокируется с объяснением.

Добавлены `edt_editor_list`, `edt_editor_close`, `edt_editor_capture_batch`. Пошаговые команды открытия, вкладок, прокрутки и снимков сохранены.

Проверки: основное и независимое ревью; 579 Java-тестов, 29 PowerShell-контрактов; отдельная EDT 2026.1.2.2 с пакетом 8 объектов и native-буфером; p2 verify-only. Три тестовых проекта и их временные артефакты убраны, базы для этих проверок не создавались. Физические сочетания клавиш и диалог Cut отдельно не проверялись.
