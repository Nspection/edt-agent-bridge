# EDT Agent Bridge 1.4.0.20261109zzworkflow12fix1

Внутренняя обработка больше не требует вспомогательного внешнего проекта и EPF. Агент может выполнить пакет шагов внутри 1С и получить результаты вместе со снимками своего окна.

- Metadata host запускается напрямую штатной ссылкой EDT runtime; его уборка независимо проверяет отсутствие в базе без verifier EPF.
- Native API protocol2 добавляет Screenshot/Capabilities. Пакет до 16 клиентских/серверных шагов делает снимки после отрисовки и возвращает проверенные пути PNG/хеши.
- Потеря ответа не запускает бизнес-шаг повторно: RPC unknown останавливает пакет; потерянный Complete ACK повторяет только неизменяемый результат.
- Тяжёлые infobase/native-host операции сериализованы отдельно от лёгких; bounded UI heartbeat показывает задержки и активные операции без payload.
- Неизменённый загруженный host при EQUAL запускается без лишнего обновления; явная incremental-команда восстанавливает синхронизацию без скрытого FULL.

Основное и независимое ревью завершены, два найденных P1 исправлены и перепроверены. 675 Java-тестов проходят. Runtime проверен в своей EDT/одноразовой базе на Windows x64 и 1С8.5.1.1522. Защита платформы при подключении Native-компоненты сохранена; пакеты не являются транзакцией, stop не откатывает записи. PrintWindow снимает главное видимое окно собственного процесса.
