# EDT Agent Bridge 1.4.0.20261117vcommands1

Исправлены два дефекта создания команд:

- `add_metadata_child(Command)` сохраняет переданные `group`, `commandParameterType`, `representation` и другие поддержанные свойства через общий typed pipeline. Работает для одиночного и пакетного создания; неверные свойства откатывают транзакцию.
- `ensure_module_artifact` для дочерней команды использует `Commands/<имя>/CommandModule.bsl` и не принимает модуль владельца за командный. Псевдонимы auto/module/command согласованы, существующее содержимое сохраняется, несовместимые kind отклоняются.

Проверены реальный MCP, XML-экспорт и холодное native BM-перечитывание в собственной EDT; отдельное независимое ревью и полный набор регрессий. Пользовательские EDT, x5 и базы не использовались; информационная база/клиент для проверки не создавались. [Контракт](command-creation.md).
