# EDT Agent Bridge 1.4.0.20261112zzzzzzcontrols4

Прямой TestClient получил типизированные действия для флажков и тумблеров, переключателей и списков, страниц и групп, числовых полей, календаря, ползунка и булевых ячеек таблицы. ИИ получает potential_actions в описании элементов и использует прежние form_action/batch/ui-входы.

Проверки состояния отделены от подтверждения отправки. Устаревшая форма, недоступное поле и неизвестный исход блокируют небезопасные действия; повторной отправки нет. Исправлен лишний второй обход формы при обычной кнопке. Native DLL/протокол/шаблон и обычные текстовые операции сохранены.

Проверено: 1057 Java +106 Python, отдельная EDT и мини-база на 8.5.1.1522, начальная настройка собственной TMS_TEST_AGENT, Native-снимки/последующие команды, модальное закрытие после PrintWindow и100 последовательных чтений. Это не заявленное исправление всех ранее наблюдавшихся таймаутов TestClient.

Календарю нужен отдельный связанный scalar expect; пустая недоказуемая таблица и сложные прикладные подтверждения остаются явными ограничениями. [Контракт](direct-testclient-controls.md), [результаты и границы проверки](review-20261112-testclient-controls.md).
