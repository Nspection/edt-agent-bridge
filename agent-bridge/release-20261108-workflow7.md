# EDT Agent Bridge 1.4.0.20261108workflow7

Три короткие команды помогают агенту работать с интерфейсом 1С через Vanessa и собирать итог проверки задачи:

- `edt_form_state`: дерево элементов, значения, сообщения, отдельный элемент или список окон; сохранённые снимки и постраничная выдача.
- `edt_form_action`: одно действие по имени — ввод/очистка, выбор значения, команда, страница, строка, флажок. Проверка ожидаемого окна перед отправкой и защита повторов; отдельные низкоуровневые команды сохранены.
- `edt_task_report`: изменения проекта, выбранный прогон, состояние явно указанных журналов данных и сохранённые наблюдения формы. Команда не запускает тесты и не продолжает наборы данных.

После основного и независимого ревью исправлены очистка пустым значением, список окон без активной формы, конкурентная проверка окна и возврат завершённого результата при остановленном менеджере. Значения формы исключены из общих журналов UI-инструментов, опроса фоновых заданий и MCP trace; сами MCP-ответы сохраняют нужные данные.

Проверки: 539 Java-тестов, границы standalone-пакета, штатный p2 verify-only в отдельном профиле. В собственной EDT 2026.1.2.2 проверен настоящий HTTP-маршрут с управляемым сервером Vanessa-протокола и общий отчёт с одноразовой файловой базой 1С 8.3.27.2325. Это **не** живая приёмка UI на настоящем клиенте Vanessa; пользовательские формы и серверный кластер этой проверкой не охвачены. Свои тестовые база/проект/регистрации удалены, рабочая EDT пользователя не изменялась.

Установка и обновление по прежней ссылке: https://nspection.github.io/edt-agent-bridge/ . После обновления перезапустить EDT и обновить список MCP-инструментов в клиенте.
