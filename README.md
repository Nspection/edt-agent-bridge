# EDT Agent Bridge

MCP-плагин для внешних ИИ-агентов, работающих с **1C:Enterprise Development Tools**.
Самостоятельный проект: [Nspection/edt-agent-bridge](https://github.com/Nspection/edt-agent-bridge). Основан на [CodePilot1C](https://github.com/ondysss/codepilot1c-edt); история и авторство исходного проекта сохранены. Авторство, лицензии и адаптированный код EDT-MCP перечислены в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

В самом плагине нет чата, LLM-провайдеров, аккаунтов ChatGPT/CodePilot, подписок, памяти агента и подключения произвольных MCP-серверов. ИИ работает в выбранном внешнем приложении. В настройках EDT остаётся одна страница **EDT Agent Bridge** с локальным MCP-подключением.

## Возможности

- Семантический анализ BSL: методы, типы, символы, вызовы, зависимости и диагностика.
- Нативные операции EDT с метаданными, реквизитами, формами, обработчиками, правами, СКД, макетами и предопределёнными данными.
- Открытие редакторов, выбор вкладок и страниц форм, прокрутка, разворачивание и фоновые снимки.
- Отладка: условные точки, точки по исключениям, стек, переменные, вычисление выражений, шаги, продолжение и выполнение до строки.
- Создание файловой базы, загрузка DT с резервной копией перед заменой, полная первая загрузка, привязка приложения и импорт проекта из ИБ через native EDT.
- Обновление тестовой базы, запуск Vanessa, статусы, визуальные контрольные точки и очистка собственных процессов.
- Нативное сравнение и объединение проектов: план для пользователя, ручной результат BSL, вопросы ИИ в редакторе и применение через EDT с защитой от устаревшего состояния.
- Повторно используемые профили запуска. Для семантических действий Vanessa сохранён внутренний локальный протокольный клиент; общего менеджера внешних MCP-серверов нет.

## Установка и сборка

Постоянный update site для установки из EDT:

```text
https://nspection.github.io/edt-agent-bridge/
```

В EDT: **Справка → Установить новое ПО → Добавить**. Название — `EDT Agent Bridge`, адрес — ссылка выше. Выберите категорию и компонент `EDT Agent Bridge`, завершите установку и перезапустите EDT. Для последующих версий используйте штатную проверку обновлений.


[Поддерживаемая инструкция Bridge](agent-bridge/README.md) описывает самостоятельную сборку из исходников, тесты и обычный **p2 update-site ZIP**. Исходный установленный CodePilot для сборки и работы не требуется — нужна сама EDT.

Проверяемая среда: Windows x64, EDT 2026.1, JDK 17. Автоматизация Vanessa дополнительно требует PowerShell 7, установленную платформу 1С, внешний EPF Vanessa и отдельную тестовую базу. Платформа, EDT и Vanessa в дистрибутив не входят.

Идентификаторы bundle/feature `com.codepilot1c.*` сохранены для обновления на месте и совместимости workspace. **Bridge заменяет CodePilot; параллельно их не устанавливают.** Имена существующих нативных MCP-команд сохраняются.

## Подключение агента

Откройте «Параметры → EDT Agent Bridge» и скопируйте конфигурацию MCP. Сервер доступен только через loopback и требует bearer-токен. Это ключ локального подключения, а не вход в аккаунт. Токен не публикуйте.

Начните с `edt_bridge_status`, затем `edt_capabilities`. Для тестирования сначала прочитайте `edt_runner_profile(project=..., action="get")`; команды и схемы проверяйте через `edt_capabilities(include_schemas=true)`.

Подробные возможности: [автоматизация](docs/release-notes/EDT-AI-AUTOMATION.md), [редакторы](docs/release-notes/EDT-EDITOR-MCP.md), [Vanessa](docs/release-notes/MANAGED-VANESSA.md). Исторические описания override-сборки CodePilot относятся к прежней ветке; текущий Bridge собирается и устанавливается самостоятельно.
