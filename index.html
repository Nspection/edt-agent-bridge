EDT Agent Bridge

Версия 1.4.0.20261106server8

MCP для внешних ИИ-агентов: метаданные, формы, отладка, снимки, Vanessa и штатное сравнение/объединение EDT.

Обновление

В EDT: «Справка → Проверить обновления».

Для первой установки: «Справка → Установить новое ПО → Добавить». Имя: EDT Agent Bridge. Адрес:

https://nspection.github.io/edt-agent-bridge/

Выберите EDT Agent Bridge и перезапустите EDT после установки. Прежние bundle/feature ID com.codepilot1c.* сохранены для обновления на месте; Bridge заменяет CodePilot.

Новое: создание серверной ИБ и SQL-базы через EDT, загрузка DT с backup перед заменой, привязка к проекту, полная первая загрузка и серверный TestClient Vanessa. Исправлены перепривязка после перезапуска, настройки входа после DT и компонентные снимки без IrfanView.

Проверено: 288 Java-тестов, 24 проверки контроллера, живой цикл на 1С 8.3 / PostgreSQL и сценарий со снимком и продолжением по SHA256 — 1 тест, 0 ошибок. Тестовые ИБ, SQL-база, проекты и записи запуска удалены. EDT 2026.1 / JDK 17 / Windows x64.

MS SQL вживую не проверялся; административная аутентификация кластера отдельно не добавлена. Импорт через edt_project_from_application остаётся файловым. Равенство схем не сертифицирует прикладные миграции.
