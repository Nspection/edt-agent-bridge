MCP для внешних ИИ-агентов: метаданные, формы, отладка, снимки, Vanessa и штатное сравнение/объединение EDT.

Обновление

В EDT: «Справка → Проверить обновления».

Для первой установки: «Справка → Установить новое ПО → Добавить». Имя: EDT Agent Bridge. Адрес:

https://nspection.github.io/edt-agent-bridge/

Выберите EDT Agent Bridge и перезапустите EDT после установки. Используются прежние bundle/feature ID com.codepilot1c.* для обновления на месте; Bridge заменяет CodePilot.

В этой версии: native compare/merge, передача плана пользователю, колонка «Вопрос ИИ», аудит значений по умолчанию при создании объектов. Проверено: 223 теста и 24 проверки объединения в EDT 2026.1 / JDK 17 / Windows x64.
