# EDT Agent Bridge 1.4.0.20261107runtime1

## Новые возможности

- `edt_runtime_execute`: клиентский/серверный BSL, параметризованные запросы, сведения о runtime и экспортные функции EPF/ERF через VAExtension в целевом TestClient. Параметры доступны как `ПараметрыВызова`, результат задаётся в `Результат`.
- `edt_external_build`: штатная сборка `IExternalObjectDumper.dump`, путь к EPF/ERF и SHA256; артефакты сохраняются вне исходников/Git. Поддерживается удаление собственного артефакта с проверкой хеша.
- Проверено создание отдельных EDT-проектов внешних отчётов и обработок через `external_manage(create_report/create_processing)` и `IExternalObjectProjectManager.create`; инструкция дополнена точными шагами.
- Статусы, JSON-результаты, текст/стек ошибок, отмена, cleanup и защита от повторного выполнения по ключу. Используется сохранённый профиль и проверка адреса базы; конфигурация при исполнении автоматически не обновляется.

## Исправления по ревью

- Код и параметры передаются через Base64: Vanessa не подставляет свои переменные/inline-выражения в BSL. Unicode-литералы не разрезают surrogate pairs.
- Потерянный вторичный индекс запуска восстанавливается из принятого claim без повторного исполнения.
- Повреждённый, неверно адресованный или слишком большой JSON возвращает `result_invalid` с известным run_id и сохраняет возможность уборки; ошибка payload не считается успехом сценария.
- Чувствительные аргументы и результаты исключены из обычных журналов и trace MCP.
- EPF/ERF передаются штатным временным хранилищем. Для проверенного по SHA256 файла используется точечное описание защиты без повторного диалога; безопасный режим сохраняется.

## Проверки и ограничения

298 Java-регрессий и 24 контракта управляемого контроллера Vanessa прошли. В предыдущем изолированном прогоне на 8.3.27.2325 проверены создание проектов, native-сборка EPF/ERF, вызов экспортных функций (42), запросы, клиентский код (43), runtime info и намеренная ошибка со стеком. После ревью дополнительно выполнены новые native-выражения транспорта на клиенте и сервере: 42, точное сохранение `$...$`, кавычек, переносов и emoji. Это дополнительная native-проверка, не повтор всего Vanessa E2E. [Протокол](../../agent-bridge/runtime-execution-validation.md).

Нужны подготовленный профиль, отдельный менеджер Vanessa и VAExtension в целевой базе. `client_mcp` требуется отдельно для semantic UI. EPF/ERF ограничены 1 MiB, код/параметры — 128 KiB, JSON-результат — 2 MiB. Режим external вызывает экспортную функцию с одним параметром; открытие формы выполняется отдельным сценарием Vanessa. Отмена не откатывает совершённые изменения данных. Новое исполнение на кластере и платформе 8.5 отдельно не проверялось.

Тестовые базы, проекты и записи запуска убраны; рабочая EDT пользователя не изменялась. [Контракт и примеры](../../agent-bridge/runtime-execution.md).

Постоянная ссылка обновления: https://nspection.github.io/edt-agent-bridge/ . В EDT: «Справка → Проверить обновления», затем перезапуск.
