# EDT Agent Bridge 1.4.0.20261106runtime4

Выпуск от 6 ноября 2026 года. Windows x64, EDT 2026.1.2.2, JDK 17, платформа 8.5.1.1522. Проверки выполняются в отдельной EDT Agent Bridge Dev.

## Четыре исправления ревью

- **Маркер полной загрузки.** File-подключения нормализуются по пути, регистру и разделителям Windows. Маркер обязательного full reload и блокировки используют один ключ. Прежний raw-маркер для той же строки подключения продолжает распознаваться; он удаляется после успешной полной загрузки.
- **Версия приложения.** Для уже зарегистрированной ИБ выбранная версия сохраняется через native `IInfobaseManager.update` на detached-копии. Сохраняются UUID, зарегистрированные имя и подключение, остальные настройки. Сохранённая версия перечитывается и проверяется. Импорт приложения также закрепляет версию до привязки.
- **Откат переноса приложения.** `LinkageError` SDK обрабатывается наравне с Exception. Восстановление прежнего владельца выполняется и при отказе удаления частичной новой связи. Исходная ошибка сохраняется; ошибки восстановления видны в сообщении без паролей.
- **Уборка снимка.** Cleanup допускается после явного закрытия сравнения и перезапуска EDT. Отсутствующая старая сессия не затрагивает другую сессию. Дополнительно проверяется отсутствие активного native-сравнения со снимком; проверки файлов, пути и несохранённых редакторов сохранены.

## Проверки и границы

274 регрессионных теста, включая девять новых адресных проверок. Native-аудит проверяет полный цикл создания/DT/full reload/импорта/merge/backup и cleanup после close. Двухфазный аудит с реальным перезапуском проверяет канонический маркер, запись версии существующей ИБ, сохранение версии после рестарта, отложенный full reload и повторяемый cleanup снимка. Ошибка SDK для rollback воспроизводится контролируемым fault injection в регрессионных тестах.

Тестовые данные располагаются вне Git; по завершении удаляются собственные ИБ, проекты, выгрузки и регистрации. Отчёты и релизные артефакты сохраняются отдельно. Рабочая EDT TMS для испытаний не перезапускается.

Новый цикл восстановления DT и управляемая Vanessa пока ограничены файловыми ИБ. Серверные приложения используют существующие общие механизмы запуска/отладки/обновления; создание и восстановление серверной ИБ этим DT-интерфейсом не реализовано. Прикладные миграции БСП и отдельный парольный DT в этом выпуске не проверялись.
