# 1.4.0.20261107runtime3

Ревью native runtime host выявило и исправило три дефекта:

- После stop выданное задание без результата оставалось нетерминальным `delivered`. При закрытии канала оно теперь становится терминальным `outcome_unknown`, без повторного исполнения; невыданное — `cancelled`.
- После перезапуска EDT результат отменённого задания ошибочно считался неизвестным. Восстановление через сервис и новый endpoint теперь использует общие правила; отмена и сохранённый результат остаются известными.
- Лимит 128 заданий учитывал только текущий endpoint и обходился повторным start. Теперь он учитывает все сохранённые claims того же host; повторное обращение по существующему ключу доступно и при исчерпанном лимите.

317 Java-тестов прошли, включая четыре новые регрессии с реальным loopback HTTP и восстановлением из файлового журнала. P2-план обновления проверен в отдельном профиле. Изменения не затрагивают BSL-шаблон, native DLL или формат EPF; бинарные компоненты из runtime2 переиспользуются без изменений. Полный цикл в 1С в этой ревизии повторно не выполнялся; предыдущая проверка была на отдельной файловой ИБ 8.3.27, без проверки кластера/8.5. Новые тестовые базы, проекты или записи запуска не создавались; временные каталоги тестов удалены.
