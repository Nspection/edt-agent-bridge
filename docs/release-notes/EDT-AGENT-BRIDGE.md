# EDT Agent Bridge 1.4.0 — самостоятельный MCP-плагин

Из CodePilot выделен сервер нативных инструментов EDT. Название продукта и единственной страницы настроек — EDT Agent Bridge. Идентификаторы bundle/feature и каталоги workspace сохранены для совместимой замены на месте; параллельная установка с CodePilot не поддерживается.

## Состав

Из рабочего plugin-кода удалены 453 Java-файла неиспользуемых компонентов и 61 ресурс/библиотека. Самостоятельная сборка компилирует 556 исходников core/UI без исходного JAR CodePilot, runtime-kernel и встроенных LLM-библиотек. Исторические runtime/CLI/Maven-материалы остаются в репозитории вне поддерживаемого пути сборки.

В продукте отсутствуют встроенный чат, LangChain/LangGraph, LLM-провайдеры, backend-аккаунт, подписки/квоты, память агента, Graph Studio и менеджер сторонних MCP-серверов. Сохранён внутренний протокольный клиент только для семантического API локального менеджера Vanessa. Его транспортные защитные механизмы не удалены. Прежний server_id универсального менеджера больше не поддерживается.

MCP требует токен и доступен только на loopback. Маршруты OAuth-регистрации, LLM и удалённого веб-чата отсутствуют. Сохранённые ключи старых аккаунтов не используются и автоматически не удаляются из защищённого хранилища.

Каталог изменился со 140 до 123 команд: удалены 18 агентных/Git/общих команд, добавлена edt_bridge_status. Нативные инструменты BSL, метаданных, форм, макетов, диагностики, отладки, профилей и Vanessa сохранены. Полный diff каталога находится в локальном отчёте приёмки.

## Миграция workbench

Старые ChatView, GraphStudioView и MemoryInspectorView могли восстанавливаться из сохранённых перспектив после удаления расширений и показывать createErrorPart. Миграция закрывает только эти view-reference и удаляет их part/placeholder из модели e4, включая свёрнутые ярлыки и неактивные перспективы. Редакторы и остальные панели не сбрасываются. Регрессии проверяют сохранность чужих частей; живая проверка подтвердила removed=3 и отсутствие старой панели ошибки и красного ярлыка.

## Установка

[Основная инструкция](../../agent-bridge/README.md). Поддерживаемый путь — build-agent-bridge.py, test-agent-bridge.py, package-agent-bridge.py, install-agent-bridge.py. Установщик проверяет p2-план, требует закрыть EDT, сохраняет прежний профиль и bundles.info для отката. При повторе после сбоя сверяет состав профиля и хеш конфигурации; таймаут локального SDK-сканирования увеличен. Упаковщик поддерживает абсолютные и относительные пути bundle после p2-обновления.

Источник механизма упаковки: [Eclipse p2 Publisher](https://help.eclipse.org/latest/topic/org.eclipse.platform.doc.isv/guide/p2_publisher.html); установки — [Eclipse p2 Director](https://help.eclipse.org/latest/topic/org.eclipse.platform.doc.isv/guide/p2_director.html).
