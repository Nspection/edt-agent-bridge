# EDT Agent Bridge 1.4.0.20261106review3

Выпуск от 6 ноября 2026 года. Проверенная среда: Windows x64, EDT 2026.1, JDK 17.

## Сравнение и объединение

- `edt_compare`: native-сравнение локальных проектов workspace, в том числе с общим предком и разбором BSL по методам; чтение различий и передача подготовленной сессии в штатное окно EDT.
- `edt_merge_plan`: выбор правил слева/справа и native-приоритетов. `edt_merge_result`: ручной результат BSL и точечная правка текста до применения.
- `edt_merge_apply`: штатное объединение EDT после проверки хеша плана, неизменности исходников и синтаксиса custom BSL. Команда асинхронная: успешное принятие отделено от завершения.
- Колонка «Вопрос ИИ»: отметки спорных узлов, текст вопроса при наведении и выделение нужного узла. Пользователь может поправить план, самостоятельно нажать «Объединить» либо передать выполнение агенту.
- Исправлены привязка к конкретному запуску native-сессии, учёт порядка подчинённых и полных merge settings в хеше плана, повторное использование открытого редактора и повторные запросы во время его загрузки.

## Создание объектов

- Проверены 103 случая создания и 796 скалярных значений по умолчанию; 59 объектов перечитаны после перезапуска EDT.
- Исправлены создание Language, нормализация Requisite, инициализация общей формы и создание артефактов макетов.
- Не разрешённые ссылки defaults-инспектор показывает как proxy URI вместо вымышленных значений.
- Добавлена ограниченная очистка помеченных временных проектов аудита через Eclipse workspace API.

## Проверки и границы

223 standalone-регрессии и 24 интеграционные проверки сравнения/объединения прошли. На тестовых проектах подтверждены native merge, сохранение UUID основного проекта, неизменность источника/предка, отсутствие ошибок в объединённом BSL-модуле и повторное сравнение. Временные проекты удалены. Перспективы 1C, Debug и Git сохранены.

Проверка не означает перебор всех сочетаний метаданных или проверку прикладной логики в информационной базе. Физический ввод пользователя мышью, hover tooltip и пользовательское нажатие native-кнопки автоматически не воспроизводились. Сессии действуют в текущем запуске EDT; прямые источники из файлов/Git-ревизий и экспорт плана между перезапусками пока не входят в поддерживаемый интерфейс. Для больших конфигураций используйте scope по объектам.

## Обновление

В EDT используйте «Справка → Проверить обновления». Если сайт ещё не добавлен: «Справка → Установить новое ПО → Добавить», адрес `https://nspection.github.io/edt-agent-bridge/`. После установки перезапустите EDT.

Bundle/feature ID `com.codepilot1c.*` сохранены для обновления на месте. Bridge заменяет исходный CodePilot; параллельная установка не поддерживается. Существующие MCP-команды сохранены, новые команды доступны после обновления списка инструментов клиентом MCP.

Исходный CodePilot, лицензия AGPL и уведомления о заимствованиях сохранены в репозитории. Проприетарные SDK-библиотеки EDT, платформа 1С и Vanessa в дистрибутив не входят.
