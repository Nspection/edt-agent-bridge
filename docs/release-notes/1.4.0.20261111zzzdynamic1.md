# EDT Agent Bridge 1.4.0.20261111zzzdynamic1

MCP может выбрать штатное «Обновить динамически» в диалоге блокировки собственной операции. Разовый action действует на текущий update_id/хеш; поручение «всё делай сам, обновляй и запускай» можно использовать в рамках задачи без автоматического сохранения постоянного разрешения.

Явное постоянное разрешение выдаётся через policy_preview/apply и привязано к пути проекта, контексту ветки, UUID и target базы. Применяется к текущему ожидающему и будущим matching вопросам; новое обновление само не запускает. Отзыв по policy_id работает даже после отвязки без обращения к базе.

Ревью исправило cross-context случай: grant новой ветки больше не принимает окно старого pending update. Native button, исходный scope/hash, действующие MCP-права и результат SDK перепроверяются. FULL/EQUAL и ограничения платформы сохранены; перезагрузка существующих клиентов не считается доказанной. Окна доверия/безопасности не обслуживаются.

866 Java + 57 Python-контрактов прошли. Своя 8.5.1.1522: FULL dynamic/EQUAL, текущий/future persistent ответ, stale hash и revoke проверены обычным own thin client. Подготовка Python TestClient в финальной среде не прошла из-за LocalAppData redirect; клиент и UI-шаги не запускались. Кластер/структурные несовместимости не проверялись. Своя среда убрана; пользовательские EDT/базы не трогались.
