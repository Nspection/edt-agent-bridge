# EDT Agent Bridge 1.4.0.20261111zzzzzzzzvanessa1

В настройках MCP и через edt_runner_profile доступны package_status/prepare_package: плагин получает закреплённые Vanessa Single, VAExtension и client_mcp с проверкой SHA256 и кешем. При сохранении профиля можно опустить EPF/hash: загрузка и запись выполняются одним наблюдаемым job, с защитой от дублей и перезаписи изменённого профиля.

Пакетная готовность отделена от живой готовности менеджера. Получение файлов не устанавливает расширения, не меняет доверие и не запускает базу. Существующие команды подготовки/профилей сохранены.

941 Java +57 Python-проверок; собственное и независимое ревью с исправлением двух гонок/таймаута. Пакеты и профиль проверены в своей EDT, пользовательская EDT/базы не тронуты. В этом этапе менеджер и бизнес-сценарий не запускались.
