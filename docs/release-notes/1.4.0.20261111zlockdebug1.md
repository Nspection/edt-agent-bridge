# EDT Agent Bridge 1.4.0.20261111zlockdebug1

MCP возвращает агенту структурированный выбор при необходимости обновления базы перед отладкой: варианты с готовыми командами, UUID и хешем. По умолчанию агент спрашивает пользователя; task_authorized_update разрешает продолжить только при уже выданном разрешении на обновление конкретной базы.

edt_update_control наблюдает штатный вопрос блокировки и продолжает исходный update без второй загрузки. Может убрать подтверждённый собственный UI-клиент с preview/hash; пользовательские процессы не завершает. edt_debug_targets читает/меняет типы автоподключения native-отладчика и сохраняет исходные значения для защищённого восстановления. Добавлен отдельный порт в конфигурации запуска для изолированной EDT.

Ревью исправило отмену после смены/утраты привязки и ложный outcome_unknown при пустом UUID. Хеши, ownership и запрет неизвестных повторов сохранены. Запросы безопасности/доверия не автоматизируются; динамическое обновление не выбирается.

Проверки: 841 Java + 57 Python, собственная платформа 8.5.1.1522: блокировка до EQUAL, native debug settings/readback/restore, реальная отвязка association с отменой штатного JFace-вопроса. Probe не выполнял обновление данных и в продукт не включён. Собственная среда убрана, пользовательские EDT/базы не менялись. HTTP/web/mobile/cluster-предметы в исполнении не проверялись.
