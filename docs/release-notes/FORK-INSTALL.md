# Установка текущего форка

Текущий продукт — **EDT Agent Bridge**, самостоятельный MCP-плагин. Используйте [основную инструкцию](../../agent-bridge/README.md) и [отчёт перехода](EDT-AGENT-BRIDGE.md).

Прежний порядок установки override поверх исходного CodePilot относится к исторической ветке разработки. Для текущей сборки исходный CodePilot устанавливать не требуется.
