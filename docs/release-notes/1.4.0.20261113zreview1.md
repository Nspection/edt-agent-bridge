# EDT Agent Bridge 1.4.0.20261113zreview1

Исправления по независимому аудиту проекта Astra medium и собственной проверке.

- Native повторно отправляет сохранённый результат при потере POST/ACK, сохраняя запрет повторного исполнения BSL. Слишком большой результат получает явный `value_omitted`; предел полного UTF-8 JSON — 2 МиБ. Batch применяет select до ограничения результата.
- Восстановление Native после потери реестра проверяет PID, время запуска и точный startup-маркер, включая Windows/WMI. Stop удаляет устаревшие PID только после подтверждения остановки и восстановления собственного состояния окна.
- Direct TestClient сериализует startup/stop/cleanup в одном порядке блокировок, восстанавливает сохранённое состояние окна и допускает повторный stop. Поздний startup не оживляет stopping/stopped.
- Внешний host фиксирует владение файлами до долгих этапов подготовки. Последующие стадии принимают только конкретные результаты генерации с проверкой хешей; посторонние файлы и изменённые исходники сохраняются. Автогенерация EPF отключается только для нового собственного временного проекта через публичный API EDT.
- host.json записывается атомарно. Готовность ensure_current учитывает согласие, текущую привязку базы и реальные блокирующие условия. Опрос result/wait распознаёт отказ транспорта без дополнительного status.

Ранее созданные внешние host без раннего доказуемого инвентаря сохраняются для проверки: автоматическая уборка таких проектов запрещена. При потере первоначальной доставки batch нынешний Native протокол не доказывает отсутствие исполнения; автоматического повтора нет.

Проверки выполнялись только в собственной изолированной EDT и одноразовых базах. Пользовательская EDT, базы и исходники x5 не изменялись. Native DLL/ZIP переиспользованы из zpopup1 без изменения; AgentHost.epf собирается заново из текущего BSL.

1278 Java, 179 Python, 33 controller + 3 CLI + 13 startup проверок; OSGi, provenance и p2 verifyOnly пройдены. Реальные Native сценарии отказа транспорта и восстановления выполнены на 8.3.27.2325 и 8.5.1.1522. Собственное и независимое Astra medium ревью завершены, открытых подтверждённых P1/P2 нет. Свои временные объекты проверенно удалены из исходников и баз, обе одноразовые базы удалены, собственная EDT остановлена.
