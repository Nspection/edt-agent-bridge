# EDT Agent Bridge 1.4.0.20261111zzzzgrid1

Добавлена необязательная сетка и линейки для снимков редакторов EDT и сохранённых снимков Native. Оригинал остаётся в image_path, отдельная копия — в alignment.image_path. grid_step по умолчанию 20 px, допустимо 8..500; линейки добавляются снаружи изображения, координаты относятся к оригиналу.

Поддержаны одиночный снимок, capture_batch, capture у form_preview/scroll/view и runtime_host action=snapshots. Native-наблюдение не выполняет Screenshot/BSL повторно; новый ZIP компоненты не требуется.

Общая очередь ограничивает память аннотаций и не держит SWT gate. Ошибка аннотации сохраняет оригинал и возвращает явный partial. Изменённые копии не перезаписываются; запись PNG выполняется через временный файл и rename.

Ревью и независимая проверка исправили два P2: параллельный расход памяти и потерю исходного capture evidence при отказе аннотации. 882 Java-теста, 41 worker +16 table контрактов прошли; отдельная EDT и Native Windows fixture проверены. Проверка Native не является приёмкой прикладной формы 1С. Свои тестовые ресурсы убраны; пользовательская EDT и базы не менялись.
