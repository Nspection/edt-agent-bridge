# EDT Agent Bridge 1.4.0.20261111zzzzzznative1

Совместимый Native ZIP автоматически подготавливается в фоне после запуска EDT, включая запуск после установки/обновления. Плагин проверяет закреплённые SHA256 ZIP/DLL и manifest, переиспользует кеш, сохраняет повреждённый файл при восстановлении. Офлайн не блокирует EDT.

В настройках MCP добавлены состояние, автоматическое получение и повтор загрузки. Агент использует тот же сервис через edt.run op=edt_runtime_host с package_status/prepare_package/configure_package. При обычной подготовке host/intent=code путь и хеш можно не указывать; явная пара сохранена. Шаблон обработки входит в плагин; доверие платформы и разрешение на базу учитываются отдельно.

914 Java +57 Python-проверок, собственное и независимое ревью; холодная загрузка, кеш после рестарта и ремонт через MCP проверены в своей EDT. Пользовательская EDT/базы не тронуты. Python installer и Vanessa bootstrap — следующие отдельные этапы.
