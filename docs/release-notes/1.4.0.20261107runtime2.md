# 1.4.0.20261107runtime2

Новая MCP-команда `edt_runtime_host` выполняет клиентский/серверный BSL и запросы без VAExtension: через внешнюю EPF с Native API компонентой Windows x64 либо через временную обработку в метаданных. Подготовка/сборка/обновление выполняются штатными механизмами EDT. В metadata-режиме start загружает весь текущий проект в разрешённую тестовую базу через FULL reload.

Есть идентичность сеанса, этапы запуска, request_id, результат/стек ошибки, защита от повторного выполнения и возобновляемая уборка по хешам. Удаление встроенной обработки проверяется и в исходниках, и отдельным запросом метаданных после обновления базы. Изменённые исходники сохраняются для просмотра. Отмена не откатывает деловые данные.

Исправлены основная форма внешних обработок/отчётов и утечка файловых потоков BSL, мешавшая удалению Module.bsl на Windows. В GitHub Release добавлены Native API ZIP, AgentHost.epf, метаданные пакета и SHA256SUMS. Первая подготовка доверия EPF по-прежнему подчиняется защите платформы; плагин её автоматически не отключает.

313 Java-тестов, C++ контракт памяти Native API и два последовательных полных цикла на отдельной файловой ИБ 8.3.27.2325 прошли. Кластер/8.5 для нового транспорта отдельно не проверялись. Старый исполнитель через Vanessa остаётся доступен; native host не заменяет её универсальное управление интерфейсом.
