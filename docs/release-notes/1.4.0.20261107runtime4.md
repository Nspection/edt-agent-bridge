# 1.4.0.20261107runtime4

Общее ревью standalone MCP: исправлены неограниченное чтение HTTP-тела, утечка HTTP/SSE-потоков при stop, неверный GSD-ответ для неизвестного инструмента, зависание Vanessa worker при ошибке совместимости EDT и принятие passed-отчёта с Failures/Errors. Лимит тела — 16 MiB; HTTP worker pool — до 16 потоков и 64 ожидающих задач.

415 Java-тестов и 24 контракта Vanessa прошли. Постоянный набор расширен 14 группами MCP/tool-контрактов. В отдельной EDT 2026.1.2.2 проверены загрузка runtime4, все 133 уникальные схемы и Unknown tool. Native DLL, BSL-шаблон и EPF прежние. Полный цикл с базой/DT в этой ревизии повторно не выполнялся.

Собственная Dev EDT закрыта, тестовые каталоги убраны. Новые базы/проекты/записи запуска не создавались; рабочая среда пользователя не менялась.
